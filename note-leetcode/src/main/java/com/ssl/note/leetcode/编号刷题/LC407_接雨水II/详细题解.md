# LC407 接雨水 II 详细题解
## 题目理解
给定一个 m x n 的二维高度图 heightMap，每个格子表示该位置地面高度。
下雨后，水会填满低洼处，问整个地形最多能接住多少体积的雨水。
和一维接雨水不同，二维情况下水可以从上下左右四个方向流走，因此每个内部格子是否存水取决于四周所有边界围成的情况。
## 思考过程
### 第一步：哪些位置一定不能存水
边界上的格子一定不能存水，因为水会从矩阵边缘流出去。
只有内部格子才有可能存水。
### 第二步：内部格子能存多少水
想象一个内部格子被一圈更高的边界围住，水面高度由什么决定？
由围住它的所有路径中最矮的那条路径决定。
如果边界最低处只有 3，那么水面最高也只能到 3，超过 3 就会从最低点流出去。
因此某个内部格子的存水量 = 围住它的最矮边界高度 - 该格子自身高度。
### 第三步：从一维联想到二维
一维接雨水中，每个位置能接的水 = min(左边最高, 右边最高) - 当前高度。
二维可以类比：每个位置能接的水 = 从该位置走到边界的所有路径中，路径上最大值的最小值 - 当前高度。
直接对每个格子做这样的搜索复杂度太高，需要更聪明的办法。
### 第四步：为什么用最小堆
核心观察：整个矩阵的边界先确定，水只会从边界最低处往里面漏。
如果我们维护一个当前所有边界的最小堆，每次取出最矮的边界 h，那么向内部扩展时：
- 相邻的内部格子如果比 h 低，它一定能被接住水，水量就是 h - 高度。
- 因为 h 是当前所有边界中最矮的，不存在比 h 更低的出口让水溜走。
- 处理完后，这个内部格子变成新的边界。如果它存了水，它能挡住的高度就是 h；如果没存水，它能挡住的高度就是自身高度。
这就形成了一个从外向内收缩的过程，每次处理当前最弱的边界，保证正确性。
## 图示与坐标对应
示例 1：
heightMap = [
  [1,4,3,1,3,2],
  [3,2,1,3,2,4],
  [2,3,3,2,3,1]
]
坐标规则：heightMap[i][j]，i 是从上到下的行，j 是从左到右的列。
俯视矩阵：
      j=0 j=1 j=2 j=3 j=4 j=5
i=0    1   4   3   1   3   2
i=1    3  [2] [1]  3  [2]  4
i=2    2   3   3   2   3   1
方括号内的三个位置是接水点：
(1,1) 高度 2，最矮边界 3，接水 1。
(1,2) 高度 1，最矮边界 3，接水 2。
(1,4) 高度 2，最矮边界 3，接水 1。
总和 1+2+1 = 4。
示例 2：
heightMap = [
  [3,3,3,3,3],
  [3,2,2,2,3],
  [3,2,1,2,3],
  [3,2,2,2,3],
  [3,3,3,3,3]
]
这是一个标准盆地，外层高度为 3，内部逐渐下降到 1。
中心 (2,2) 高度 1，接水 3-1=2。
周围 8 个高度为 2 的格子，每个接水 3-2=1。
总接水量 = 2 + 8*1 = 10。
## 算法详细步骤
1. 初始化最小堆和访问标记数组。
2. 把矩阵最外层所有边界格子加入堆，标记为已访问。
3. 弹出堆顶元素 (x, y, h)，h 为当前最矮边界高度。
4. 遍历 (x, y) 的四个邻居 (nx, ny)。
5. 如果邻居未访问：
   - 若 heightMap[nx][ny] < h，则该位置可接水 h - heightMap[nx][ny]，累加到答案，并将 (nx, ny, h) 入堆。
   - 若 heightMap[nx][ny] >= h，则不可接水，将 (nx, ny, heightMap[nx][ny]) 入堆。
6. 标记邻居为已访问。
7. 重复步骤 3-6 直到堆为空。
为什么正确：每次弹出的 h 是当前所有边界中最矮的，任何比 h 低的内部格子都不可能通过其他路径把水排出去，因此一定能存水。
## 完整代码
```java
package com.ssl.note.leetcode.编号刷题.LC407_接雨水II;
import java.util.PriorityQueue;
public class Solution {
    public int trapRainWater(int[][] heightMap) {
        if (heightMap == null || heightMap.length == 0 || heightMap[0].length == 0) {
            return 0;
        }
        int m = heightMap.length;
        int n = heightMap[0].length;
        if (m < 3 || n < 3) {
            return 0;
        }
        // 最小堆按高度升序，存储 [行, 列, 作为边界的高度]
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) -> a[2] - b[2]);
        boolean[][] visited = new boolean[m][n];
        // 左右两列边界入堆
        for (int i = 0; i < m; i++) {
            minHeap.offer(new int[]{i, 0, heightMap[i][0]});
            minHeap.offer(new int[]{i, n - 1, heightMap[i][n - 1]});
            visited[i][0] = true;
            visited[i][n - 1] = true;
        }
        // 上下两行边界入堆（角点已处理，从 1 到 n-2）
        for (int j = 1; j < n - 1; j++) {
            minHeap.offer(new int[]{0, j, heightMap[0][j]});
            minHeap.offer(new int[]{m - 1, j, heightMap[m - 1][j]});
            visited[0][j] = true;
            visited[m - 1][j] = true;
        }
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        int res = 0;
        while (!minHeap.isEmpty()) {
            int[] cur = minHeap.poll();
            int x = cur[0];
            int y = cur[1];
            int h = cur[2];
            for (int[] dir : dirs) {
                int nx = x + dir[0];
                int ny = y + dir[1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n || visited[nx][ny]) {
                    continue;
                }
                visited[nx][ny] = true;
                if (heightMap[nx][ny] < h) {
                    res += h - heightMap[nx][ny];
                    minHeap.offer(new int[]{nx, ny, h});
                } else {
                    minHeap.offer(new int[]{nx, ny, heightMap[nx][ny]});
                }
            }
        }
        return res;
    }
}
```
## 复杂度分析
时间复杂度：O(mn log(mn))。
每个格子最多入堆一次、出堆一次，堆操作复杂度为 O(log(mn))。
空间复杂度：O(mn)。
最小堆最多存储所有格子，访问标记数组大小为 mn。
## 关键记忆点
- 边界先入堆，边界不能存水。
- 每次取最矮边界，它决定内部低洼格子的水面高度。
- 内部格子比边界矮就接水，接水后变成高度为 h 的新边界。
- 内部格子比边界高或相等就不接水，以自身高度成为新边界。
