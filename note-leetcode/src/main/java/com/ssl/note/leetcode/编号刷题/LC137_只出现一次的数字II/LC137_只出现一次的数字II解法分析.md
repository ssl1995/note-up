# LC137_只出现一次的数字 II

## 题目描述

给你一个整数数组 `nums`，除某个元素仅出现 **一次** 外，其余每个元素都恰出现 **三次**。请你找出并返回那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法且使用常数级空间来解决此问题。

示例 1：
```
输入：nums = [2,2,3,2]
输出：3
```

示例 2：
```
输入：nums = [0,1,0,1,0,1,99]
输出：99
```

## 解法概览

| 解法 | 思路 | 核心公式 | 时间复杂度 | 空间复杂度 |
|------|------|----------|------------|------------|
| 按位统计 | 逐位统计 1 的个数，对 3 取余 | `count % 3` | O(n) | O(1) |
| 位运算状态机 | 用 ones/twos 模拟三进制计数 | `ones=(ones^num)&~twos`<br>`twos=(twos^num)&~ones` | O(n) | O(1) |

## 记忆口诀

出现三次不简单，异或抵消已不行；按位统计对三余，状态机来更高效。

## 解法一：按位统计（直观理解）

### 思路

对于二进制的每一位：
- 出现 3 次的数字，在该位上贡献的 1 的个数一定是 3 的倍数
- 只出现 1 次的数字，如果该位是 1，就会多出来 1 个 1

所以，把每个位上所有数字的 1 累加，对 3 取余，剩下的就是答案在该位上的值。

### 核心公式

- 对第 `i` 位统计：`count += (num >>> i) & 1`
- 如果 `count % 3 != 0`，则答案的第 `i` 位为 1

### 代码示例

```java
public int singleNumber(int[] nums) {
    int res = 0;
    for (int i = 0; i < 32; i++) {
        int count = 0;
        for (int num : nums) {
            count += (num >>> i) & 1;
        }
        if (count % 3 != 0) {
            res |= (1 << i);
        }
    }
    return res;
}
```

### 复杂度分析

- 时间复杂度：O(32 × n) = O(n)
- 空间复杂度：O(1)

### 优缺点

- 优点：思路直观，容易理解，不容易写错
- 缺点：常数因子较大，需要 32 次遍历数组

## 解法二：位运算状态机（最优解）

### 思路

用两个整数模拟一个**三进制计数器**：
- `ones`：记录当前出现 1 次的位
- `twos`：记录当前出现 2 次的位
- 出现 3 次时，自动清零（00）

两个二进制位可以表示三种状态：

| 出现次数 | twos | ones |
|---------|------|------|
| 0 次 | 0 | 0 |
| 1 次 | 0 | 1 |
| 2 次 | 1 | 0 |
| 3 次 | 0 | 0 |

### 状态转移推导

对于每一位，当前状态为 `(twos, ones)`，新来一个位 `b`：

| 当前 (twos, ones) | b | 下一个 (twos', ones') |
|-------------------|---|----------------------|
| 00 | 0 | 00 |
| 00 | 1 | 01 |
| 01 | 0 | 01 |
| 01 | 1 | 10 |
| 10 | 0 | 10 |
| 10 | 1 | 00 |

由真值表可得：

```
ones' = (~twos) & (ones ^ b)
twos' = (~ones') & (twos ^ b)
```

### 核心公式

```java
ones = (ones ^ num) & ~twos;
twos = (twos ^ num) & ~ones;
```

### 代码示例

```java
public int singleNumber(int[] nums) {
    int ones = 0;  // 记录出现 1 次的位
    int twos = 0;  // 记录出现 2 次的位

    for (int num : nums) {
        ones = (ones ^ num) & ~twos;
        twos = (twos ^ num) & ~ones;
    }

    return ones;
}
```

### 复杂度分析

- 时间复杂度：O(n)，只遍历数组一次
- 空间复杂度：O(1)

### 优缺点

- 优点：时间最优，空间最优，代码简洁
- 缺点：理解难度较大，需要理解三进制计数器的状态转移

## 手动推演示例

`nums = [2, 2, 3, 2]`

二进制：2 = 010，3 = 011

初始：`ones = 000`, `twos = 000`

**第 1 个 2（010）：**
```
ones = (000 ^ 010) & ~000 = 010
twos = (000 ^ 010) & ~010 = 000
```
状态：第 1 位出现 1 次

**第 2 个 2（010）：**
```
ones = (010 ^ 010) & ~000 = 000
twos = (000 ^ 010) & ~000 = 010
```
状态：第 1 位出现 2 次

**第 3 个 3（011）：**
```
ones = (000 ^ 011) & ~010 = 001
twos = (010 ^ 011) & ~001 = 000
```
状态：第 0 位出现 1 次，第 1 位抵消

**第 4 个 2（010）：**
```
ones = (001 ^ 010) & ~000 = 011
twos = (000 ^ 010) & ~011 = 000
```

最终：`ones = 011 = 3`，答案为 3。

## 面试回答模板

面试官好，这道题是 LC136 的升级版，其他数字出现 3 次而不是 2 次，所以不能简单用异或抵消。

我的思路是：对整数的每一位，统计所有数字在该位上 1 出现的次数，对 3 取余，剩下的就是只出现一次的那个数字在该位上的值。可以用两个变量 `ones` 和 `twos` 来模拟三进制计数器，`ones` 记录出现 1 次的位，`twos` 记录出现 2 次的位，出现 3 次时自动清零。最后 `ones` 就是答案。

如果现场想不起来状态机公式，也可以先写按位统计的版本，时间复杂度同样是 O(n)。

## 解题技巧总结

- 技巧 1：当其他数字出现 k 次时，可以考虑按位统计并对 k 取余
- 技巧 2：用状态机可以把多次遍历优化为一次遍历
- 技巧 3：`ones` 先更新，`twos` 后更新，更新时要用对方的新/旧值保护
