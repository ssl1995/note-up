# LC260_只出现一次的数字 III

## 题目描述

给你一个整数数组 `nums`，其中恰好有两个元素只出现一次，其余所有元素均出现两次。找出只出现一次的那两个元素。你可以按 **任意顺序** 返回答案。

你必须设计并实现线性时间复杂度的算法且仅使用常量额外空间来解决此问题。

示例 1：
```
输入：nums = [1,2,1,3,2,5]
输出：[3,5]
解释：[5, 3] 也是有效的答案。
```

示例 2：
```
输入：nums = [-1,0]
输出：[-1,0]
```

示例 3：
```
输入：nums = [0,1]
输出：[1,0]
```

## 解法概览

| 解法 | 思路 | 核心步骤 | 时间复杂度 | 空间复杂度 |
|------|------|----------|------------|------------|
| 异或 + 分组 | 全员异或后按不同位分组 | `xor = a ^ b`<br>`mask = xor & (-xor)`<br>按 mask 分组异或 | O(n) | O(1) |

## 记忆口诀

两个单身要分组，异或找到不同位；按位一分为二，各组异或得答案。

## 解法：异或 + 分组

### 思路

LC136 中只有一个数字出现一次，用全员异或可以直接得到答案。

LC260 中有两个数字 `a` 和 `b` 各出现一次，全员异或后得到的是 `a ^ b`，无法直接分离出 `a` 和 `b`。

关键观察：
- 因为 `a != b`，所以 `a ^ b != 0`
- `a ^ b` 的二进制中至少有一位是 1
- 这个为 1 的位说明：`a` 和 `b` 在该位上不同，一个为 0，一个为 1

利用这个不同位，可以把数组分成两组：
- 第一组：该位为 0 的数字
- 第二组：该位为 1 的数字

相同的数字必然被分到同一组，`a` 和 `b` 被分到不同组。

然后对两组分别进行全员异或，每组中成对的数字相互抵消，剩下的就是 `a` 和 `b`。

### 核心步骤

1. **全员异或**：`xor = a ^ b`
2. **找到不同位**：`mask = xor & (-xor)`，取 `xor` 最低位的 1
3. **按位分组**：根据 `num & mask` 的结果把数字分成两组
4. **分组异或**：分别对两组异或，得到 `a` 和 `b`

### 关键技巧：`xor & (-xor)`

`-xor` 是 `xor` 的补码表示下的相反数。

`xor & (-xor)` 的作用是取 `xor` 二进制表示中**最低位的 1**。

例如：
- `xor = 6`，二进制 `110`
- `-xor` 在补码下是 `...11111010`
- `xor & (-xor) = 110 & ...1010 = 010 = 2`

所以 `mask = 2`，表示第 1 位是 `a` 和 `b` 的不同位。

### 代码示例

```java
public int[] singleNumber(int[] nums) {
    int xor = 0;
    // 第一步：全部异或，得到 a ^ b
    for (int num : nums) {
        xor ^= num;
    }

    // 第二步：取 xor 最低位的 1，作为分组依据
    int mask = xor & (-xor);

    int a = 0;
    int b = 0;

    // 第三步：按 mask 分组，分别异或
    for (int num : nums) {
        if ((num & mask) == 0) {
            a ^= num;
        } else {
            b ^= num;
        }
    }

    return new int[]{a, b};
}
```

### 手动推演

`nums = [1, 2, 1, 3, 2, 5]`

二进制：
- 1 = 001
- 2 = 010
- 3 = 011
- 5 = 101

**第一步：全员异或**

```
xor = 1 ^ 2 ^ 1 ^ 3 ^ 2 ^ 5
    = (1 ^ 1) ^ (2 ^ 2) ^ (3 ^ 5)
    = 0 ^ 0 ^ (3 ^ 5)
    = 3 ^ 5
    = 011 ^ 101
    = 110
    = 6
```

**第二步：取最低位 1**

```
xor = 6 = 110
-xor = ...1010
mask = xor & (-xor) = 110 & ...1010 = 010 = 2
```

`mask = 2`，表示第 1 位是 `a` 和 `b` 的不同位。

**第三步：按第 1 位分组**

| num | 二进制 | 第 1 位 | 分组 |
|-----|--------|---------|------|
| 1 | 001 | 0 | a 组 |
| 2 | 010 | 1 | b 组 |
| 1 | 001 | 0 | a 组 |
| 3 | 011 | 1 | b 组 |
| 2 | 010 | 1 | b 组 |
| 5 | 101 | 0 | a 组 |

**第四步：分组异或**

a 组：`1 ^ 1 ^ 5 = 5`

b 组：`2 ^ 3 ^ 2 = 3`

最终答案：`[5, 3]` 或 `[3, 5]` ✅

### 复杂度分析

- 时间复杂度：O(n)，遍历数组两次
- 空间复杂度：O(1)，只使用了几个变量

### 优缺点

- 优点：时间最优，空间最优，思路清晰
- 缺点：需要理解异或的性质和 `xor & (-xor)` 的技巧

## 面试回答模板

面试官好，这道题有两个数字各出现一次，其他都出现两次。我的思路是：

1. 首先全员异或，因为成对的数字会抵消，所以得到的是两个单身数的异或值 `a ^ b`。
2. 由于这两个数不同，异或结果一定不为 0，至少有一位是 1。这个位说明两个数在该位上不同。
3. 我用 `xor & (-xor)` 取出最低位的 1，作为分组标志。
4. 根据这一位把数组分成两组，两个单身数一定在不同组。
5. 最后对两组分别异或，得到两个答案。

时间复杂度 O(n)，空间复杂度 O(1)。

## 解题技巧总结

- 技巧 1：`a ^ a = 0`，`a ^ 0 = a`，成对出现的数字可以相互抵消
- 技巧 2：如果 `a != b`，则 `a ^ b != 0`，至少有一位为 1
- 技巧 3：`xor & (-xor)` 可以快速取出 `xor` 最低位的 1
- 技巧 4：按不同位分组是解决“两个单身数”问题的关键
