# LCP74 最强祝福力场：坐标翻倍 + 离散化 + 二维差分
> 题目：`forceField[i] = [x, y, side]` 表示以 `(x, y)` 为中心、边长为 `side` 的正方形力场。任意一点的力场强度 = 覆盖该点的力场数量，求最强处的力场强度（即最大重叠次数）。
> 示例：输入 `[[4,4,6],[7,5,3],[1,6,2],[5,6,3]]`，输出 `3`。
## 一、题目本质：二维区域最大重叠次数
- 每个力场 = 一个矩形区域，求平面上被最多矩形覆盖的点的覆盖次数。
- 这正是**二维差分数组**的标准应用：每个矩形区域 `+1`，最后还原数组取最大值。
- 但有个障碍：**坐标范围太大**（x、y 可达 10^9 级别），不可能直接开 `int[坐标][坐标]` 的差分数组 → 需要**离散化**。
- 还有个障碍：边长 `side` 为奇数时，边界 `x ± side/2` 是 **x.5 的小数** → 需要**坐标翻倍**技巧。
- 所以本题 = **坐标翻倍（消小数）+ 离散化（压缩大坐标）+ 二维差分（区域 +1）+ 前缀和还原取最大值**，四板斧组合。
## 二、技巧 1：坐标翻倍（×2 消小数）
正方形中心 `(x, y)`、边长 `side`，覆盖范围是闭区间：
```
x ∈ [x - side/2, x + side/2]
y ∈ [y - side/2, y + side/2]
```
- 当 `side` 为奇数（如 3），边界是 `.5` 小数，如中心 x=7、side=3 → `x ∈ [5.5, 8.5]`。
- **解法：把所有坐标 ×2**，用 `(x << 1) - side` 和 `(x << 1) + side` 表示左右边界，全部变成整数，且**重叠关系完全不变**（等比缩放不改变谁覆盖谁）。
```java
xs[k++] = (x << 1) - r;  // 左边界 ×2
xs[k++] = (x << 1) + r;  // 右边界 ×2
```
- 额外好处：力场覆盖是**闭区间**，两个矩形边缘刚好相接也算重叠（如 A 覆盖 x∈[1,7]，B 覆盖 x∈[7,10]，点 x=7 被两个都覆盖）。翻倍 + 离散化后，每个边界坐标值本身会成为独立的一格，相接的情况被天然正确处理，无需特判。
- 注意用 `long` 接收：坐标 ×2 再加上 side，可能超 int 范围。
## 三、技巧 2：离散化（大坐标 → 小编号）
**核心思想**：n 个矩形最多只有 `2n` 个不同的 x 边界、`2n` 个不同的 y 边界。真正影响答案的只有这些**边界坐标的相对顺序**，坐标之间的"空隙大小"无关紧要。把稀疏的大坐标压缩成 `1 ~ 2n` 的连续编号，差分数组只需开 `O(n) × O(n)`。
**离散化三步**：
1. **收集**：把每个矩形的左右边界放进 `xs`、上下边界放进 `ys`（各 `2n` 个）。
2. **排序 + 去重**：排序后双指针去重，返回有效长度。
3. **映射（二分查找）**：原坐标值 → 在有序无重复数组中的编号。
```java
// 排序 + 去重，返回有效长度
// [50,70,30,70,30,60] → 排序 [30,30,50,60,70,70] → 去重 [30,50,60,70]，有效长度 4
public int sort(long[] nums) {
  Arrays.sort(nums);
  int size = 1;
  for (int i = 1; i < nums.length; i++) {
    if (nums[i] != nums[size - 1]) {
      nums[size++] = nums[i]; // 与上一个有效值不同才收录
    }
  }
  return size;
}
```
```java
// 二分查找 v 的编号（v 保证在数组中），编号从 1 开始（给差分数组的哨兵让位）
public int rank(long[] nums, long v, int size) {
  int l = 0, r = size - 1, m, ans = 0;
  while (l <= r) {
    m = (l + r) / 2;
    if (nums[m] >= v) { // 找 >= v 的最左位置
      ans = m;
      r = m - 1;
    } else {
      l = m + 1;
    }
  }
  return ans + 1; // 0-based 下标 → 1-based 编号
}
```
**示例**：`[30,50,60,70]`（有效长度 4）中查 60 → 下标 2 → 编号 3。
## 四、技巧 3：二维差分 + 前缀和还原
离散化后就是标准的二维差分模板（详见《二维前缀和与二维差分数组总结》）：
```java
int[][] diff = new int[sizex + 2][sizey + 2]; // +2：哨兵 + c+1/d+1 防越界
for (int i = 0; i < n; i++) {
  // 每个矩形的 4 个边界 → 二分映射成编号
  a = rank(xs, (x << 1) - r, sizex); // 左
  b = rank(ys, (y << 1) - r, sizey); // 上
  c = rank(xs, (x << 1) + r, sizex); // 右
  d = rank(ys, (y << 1) + r, sizey); // 下
  add(diff, a, b, c, d);             // 区域 +1
}
// 前缀和还原，同时扫出最大值
int ans = 0;
for (int i = 1; i < diff.length; i++)
  for (int j = 1; j < diff[0].length; j++) {
    diff[i][j] += diff[i - 1][j] + diff[i][j - 1] - diff[i - 1][j - 1];
    ans = Math.max(ans, diff[i][j]);
  }
```
```java
// 二维差分四角操作：左上加、右下加，另外两个减
public void add(int[][] diff, int a, int b, int c, int d) {
  diff[a][b] += 1;
  diff[c + 1][d + 1] += 1;
  diff[c + 1][b] -= 1;
  diff[a][d + 1] -= 1;
}
```
**小优化**：本题把"还原"和"取最大值"合并在同一个双重循环里，省一次遍历。
## 五、完整示例推演
输入 `forceField = [[4,4,6],[7,5,3],[1,6,2],[5,6,3]]`。
**第 1 步：坐标翻倍，求每个矩形的覆盖区间**
| 力场 | 原始 x 区间 | 原始 y 区间 | ×2 后 x | ×2 后 y |
| --- | --- | --- | --- | --- |
| ① (4,4,6) | [1, 7] | [1, 7] | [2, 14] | [2, 14] |
| ② (7,5,3) | [5.5, 8.5] | [3.5, 6.5] | [11, 17] | [7, 13] |
| ③ (1,6,2) | [0, 2] | [5, 7] | [0, 4] | [10, 14] |
| ④ (5,6,3) | [3.5, 6.5] | [4.5, 7.5] | [7, 13] | [9, 15] |
可以看到 ②④ 的边界是 `.5` 小数（5.5、8.5、3.5…），×2 后全部化为整数，这就是翻倍的必要性。
**第 2 步：离散化**
```
xs 收集：[2,14, 11,17, 0,4, 7,13] → 排序去重：[0,2,4,7,11,13,14,17]，sizex = 8
ys 收集：[2,14, 7,13, 10,14, 9,15] → 排序去重：[2,7,9,10,13,14,15]，sizey = 7
```
差分数组只需开 `10 × 9`，而不是按坐标开 `18 × 16` 甚至更大。
**第 3 步：每个矩形映射编号，区域 +1**
| 力场 | x 编号 [a,c] | y 编号 [b,d] |
| --- | --- | --- |
| ① [2,14]×[2,14] | [2, 7] | [1, 6] |
| ② [11,17]×[7,13] | [5, 8] | [2, 5] |
| ③ [0,4]×[10,14] | [1, 3] | [4, 6] |
| ④ [7,13]×[9,15] | [4, 6] | [3, 7] |
**第 4 步：还原取最大值**
- 还原后，编号 x∈[5,6]、y∈[3,5] 附近的格子被 ①②④ 三个矩形同时覆盖 → 值为 3。
- 对应回原坐标：x ∈ [5.5, 6.5]、y ∈ [4.5, 6.5] 这片区域被 3 个力场覆盖，答案 = 3。
## 六、复杂度分析
- 排序：`O(n log n)`
- n 个矩形各做 4 次二分映射：`O(n log n)`
- 差分数组大小最大 `2n × 2n`，还原 + 取最大值：`O(n²)`
- **总复杂度 `O(n²)`**，空间 `O(n²)`。n ≤ 100 时完全够用。
## 七、易错点清单
1. **忘记坐标翻倍**：side 为奇数时边界是 `.5`，不翻倍就无法用整数数组处理。
2. **int 溢出**：坐标 ×2 再 ±side 可能超 int，收集边界的数组要用 `long`。
3. **rank 返回 1-based 编号**：`return ans + 1`，给差分数组第 0 行/列留哨兵位；写漏会导致 add 访问 -1 越界或哨兵失效。
4. **diff 开 `+2`**：`sizex + 2`，因为 add 会访问 `c+1`、`d+1`（c 最大等于 sizex）。
5. **去重逻辑**：`nums[i] != nums[size - 1]` 才收录，比较的是"上一个有效值"，不是 `nums[i-1]`。
6. **二分是找 `>= v` 的最左位置**：因为 v 一定存在于数组中，这样正好定位到它自己。
7. **两次遍历 fields**：第一次收集坐标，第二次再算边界做映射，两次的边界计算式 `(x<<1)±r` 必须完全一致，别写串。
## 八、套路总结：什么时候用这套组合拳
- **区域叠加计数**（求最大重叠次数 / 覆盖面积）→ 差分。
- **坐标范围大但矩形数量少** → 离散化（压缩坐标）。典型题：LC850 矩形面积 II、LC391 完美矩形。
- **边界可能出现小数**（中心 ± 半边长）→ 坐标 ×2 消小数。
- 一维版本类比：LC1109 航班预订统计（一维差分）、会议室系列（扫描线/差分思想）。
