# LC772 基本计算器 III - 详细题解
## 一、题目分析
### 题目要求
实现一个基本的计算器来计算一个简单的表达式字符串。表达式字符串只包含非负整数、`+`、`-`、`*`、`/`、左括号 `(`、右括号 `)` 和空格。整数除法需要向下取整。
### 输入输出示例
```
输入: "(2*(3-4))*5"
输出: -10
输入: "1+2*3-4/2"
输出: 5
输入: "((2+3)*(1+2))"
输出: 15
```
### 难点分析
这道题相比基本计算器 I 和 II，增加了**括号嵌套**的复杂度：
1. **运算符优先级**：乘除优先于加减
2. **括号优先级**：括号内的表达式优先计算
3. **嵌套结构**：括号可以无限嵌套，需要递归处理
4. **位置同步**：递归返回后，需要知道从字符串的哪个位置继续解析

## 二、算法设计思路
### 2.1 整体架构
本解法采用 **递归 + 双栈** 的设计：
```
┌─────────────────────────────────────────┐
│           calculate(str)                │
│         入口函数，初始化状态              │
└─────────────────┬───────────────────────┘
                  │ 调用
                  ▼
┌─────────────────────────────────────────┐
│              f(s, i)                    │
│    递归计算 s[i...] 直到 ) 或结束        │
│    使用双栈处理当前层级运算               │
└─────────────────┬───────────────────────┘
                  │ 遇到 (
                  ▼ 递归
            ┌─────────────┐
            │   子问题     │
            │ 计算括号内    │
            └─────────────┘
```
### 2.2 核心设计决策
#### 决策一：为什么用递归处理括号？
**问题**：括号可以嵌套，如 `((1+2)*3)`，如何正确处理？
**方案对比**：
| 方案 | 思路 | 缺点 |
|------|------|------|
| 栈模拟 | 遇到 `(` 压栈，遇到 `)` 弹栈计算 | 需要额外设计状态保存机制，代码复杂 |
| 递归 | 遇到 `(` 递归计算子表达式 | 代码简洁，天然匹配嵌套结构 |
**选择递归的原因**：
1. **结构匹配**：括号是嵌套结构，递归也是嵌套调用，天然对应
2. **状态隔离**：每层递归有自己的局部变量（数字栈、运算符栈），互不干扰
3. **代码简洁**：不需要手动管理栈帧，编译器自动处理
#### 决策二：为什么需要全局变量 `where`？
**问题**：递归函数返回计算结果后，上层如何知道继续解析的位置？
**示例**：
```
表达式: "2*(1+3)+5"
           ↑
           递归计算 (1+3) 返回 4
           但上层不知道 i 已经移动到了位置 6
```
**解决方案**：用全局变量 `where` 记录当前解析位置
- 递归返回前，设置 `where = i`（当前停止的位置）
- 上层从 `where + 1` 继续解析
**为什么不用返回值传递？**
- 需要同时返回：计算结果 + 解析位置
- Java 不支持多返回值，需要封装对象，增加复杂度
- 全局变量更简单直接
#### 决策三：为什么用双栈（数字栈 + 运算符栈）？
**单栈方案的问题**：
如果用一个栈同时存数字和运算符，需要额外标记类型，处理逻辑复杂。
**双栈的优势**：
```
数字栈: [2, 3, 4]     ← 只存操作数
运算符栈: [+, *]       ← 只存运算符
```
**配合优先级处理**：
- 遇到 `*` 或 `/`：立即用数字栈顶元素与当前数计算
- 遇到 `+` 或 `-`：数字和运算符分别入栈，等待后续处理
#### 决策四：为什么乘除要立即计算，加减要入栈？
**优先级规则**：乘除 > 加减
**反例（如果不立即计算）**：
```
表达式: 2 + 3 * 4
错误处理（全部入栈）：
  数字栈: [2, 3, 4]
  运算符栈: [+, *]
  最后计算: 2 + 3 * 4 = 5 * 4 = 20 ❌（错误！）
正确处理（乘除立即计算）：
  遇到 * 时: 3 * 4 = 12，替换栈顶
  数字栈: [2, 12]
  运算符栈: [+]
  最后计算: 2 + 12 = 14 ✅
```
**设计原则**：高优先级运算符立即归约，低优先级运算符延迟处理。
#### 决策五：为什么最后要 `push(numbers, ops, cur, '+')`？
**场景**：循环结束时，最后一个数字还没有入栈
```
表达式: "1+2"
解析过程:
  '1' → cur = 1
  '+' → push(1, '+') → 数字栈[1], 运算符栈['+']
  '2' → cur = 2
  结束 → cur = 2 还在手里，没入栈！
```
**解决方案**：用一个虚拟运算符触发入栈
- 选择 `'+'` 是因为任何运算符都可以，不影响结果
- push 后数字栈 [1, 2]，运算符栈 ['+', '+']
- compute 时只用到前 n-1 个运算符，最后一个被忽略

## 三、代码结构详解
### 3.1 整体结构
```java
public class Solution {
    public static int where;              // 全局位置指针
    
    public static int calculate(String str)   // 入口
    public static int f(char[] s, int i)      // 递归核心
    public static void push(...)              // 入栈处理（含优先级）
    public static int compute(...)            // 最终计算
}
```
### 3.2 函数职责
| 函数 | 职责 | 关键逻辑 |
|------|------|----------|
| `calculate` | 初始化 | 重置 where，调用 f |
| `f` | 递归计算 | 解析字符，遇到 `(` 递归，遇到 `)` 或结束返回 |
| `push` | 入栈 | 根据运算符优先级决定立即计算或入栈 |
| `compute` | 最终计算 | 处理剩余的加减法 |
### 3.3 递归函数 `f` 详解
```java
public static int f(char[] s, int i) {
    List<Integer> numbers = new ArrayList<>();  // 数字栈
    List<Character> ops = new ArrayList<>();    // 运算符栈
    int cur = 0;                                 // 当前解析的数字
    
    // 循环条件：未越界 且 未遇到 )
    while (i < s.length && s[i] != ')') {
        if (s[i] >= '0' && s[i] <= '9') {
            // 情况1：数字 → 累积到 cur
            cur = cur * 10 + s[i++] - '0';
        } else if (s[i] != '(') {
            // 情况2：运算符 → push 当前数字和运算符
            push(numbers, ops, cur, s[i++]);
            cur = 0;  // 重置，准备解析下一个数字
        } else {
            // 情况3：左括号 → 递归计算子表达式
            cur = f(s, i + 1);      // 递归结果作为当前数字
            i = where + 1;          // 从递归停止的位置继续
        }
    }
    
    // 循环结束：最后一个数字入栈
    push(numbers, ops, cur, '+');
    where = i;  // 记录停止位置，供上层使用
    
    return compute(numbers, ops);
}
```
**关键点**：
- `cur` 的作用：累积多位数字，如 "123" → cur = 123
- 三种情况的分支顺序：数字 → 运算符 → 左括号
- `where` 的更新时机：递归返回前
### 3.4 入栈函数 `push` 详解
```java
public static void push(List<Integer> numbers, List<Character> ops, int cur, char op) {
    int n = numbers.size();
    
    // 情况1：栈空 或 栈顶是加减 → 直接入栈
    if (n == 0 || ops.get(n - 1) == '+' || ops.get(n - 1) == '-') {
        numbers.add(cur);
        ops.add(op);
    } 
    // 情况2：栈顶是乘除 → 立即计算
    else {
        int topNumber = numbers.get(n - 1);
        char topOp = ops.get(n - 1);
        
        if (topOp == '*') {
            numbers.set(n - 1, topNumber * cur);  // 乘法立即计算
        } else {
            numbers.set(n - 1, topNumber / cur);  // 除法立即计算
        }
        ops.set(n - 1, op);  // 替换运算符为当前运算符
    }
}
```
**执行示例**：
```
表达式: 2 * 3 + 4
步骤1: push(2, '*')
  栈空 → 数字栈[2], 运算符栈['*']
步骤2: push(3, '+')
  栈顶是 * → 立即计算 2*3=6
  数字栈[6], 运算符栈['+']  ← 运算符被替换
步骤3: push(4, '+')  // 结束时调用
  栈顶是 + → 直接入栈
  数字栈[6, 4], 运算符栈['+', '+']
```
### 3.5 计算函数 `compute` 详解
```java
public static int compute(List<Integer> numbers, List<Character> ops) {
    int n = numbers.size();
    int ans = numbers.get(0);  // 从第一个数字开始
    
    // 遍历前 n-1 个运算符
    for (int i = 0; i < n - 1; i++) {
        if (ops.get(i) == '+') {
            ans += numbers.get(i + 1);
        } else {
            ans -= numbers.get(i + 1);
        }
    }
    return ans;
}
```
**为什么只遍历 n-1 个运算符？**
- 运算符栈有 n 个元素，但最后一个是我们手动添加的 `'+'`
- 实际有效的运算符只有 n-1 个
- 数字有 n 个，运算符 n-1 个，正好对应

## 四、完整示例推演
### 示例：`(2*(3-4))*5`
#### 第一层：最外层
```
初始: i=0, where=0, cur=0, 数字栈=[], 运算符栈=[]
i=0: '(' → 递归进入第二层，从 i=1 开始
     ↓
```
#### 第二层：`(2*(3-4))`
```
初始: i=1, cur=0, 数字栈=[], 运算符栈=[]
i=1: '2' → cur = 2
i=2: '*' → push(2, '*')
          栈空 → 数字栈[2], 运算符栈['*']
          cur = 0
i=3: '(' → 递归进入第三层，从 i=4 开始
     ↓
```
#### 第三层：`(3-4)`
```
初始: i=4, cur=0, 数字栈=[], 运算符栈=[]
i=4: '3' → cur = 3
i=5: '-' → push(3, '-')
          栈空 → 数字栈[3], 运算符栈['-']
          cur = 0
i=6: '4' → cur = 4
i=7: ')' → 循环结束
push(4, '+') → 数字栈[3,4], 运算符栈['-','+']
where = 7
compute: 3 - 4 = -1
返回 -1
```
#### 回到第二层
```
cur = -1 (递归结果)
i = where + 1 = 8
i=8: ')' → 循环结束
push(-1, '+') → 栈顶是 '*'
               立即计算: 2 * (-1) = -2
               数字栈[-2], 运算符栈['+']
where = 8
compute: -2
返回 -2
```
#### 回到第一层
```
cur = -2 (递归结果)
i = where + 1 = 9
i=9: '*' → push(-2, '*')
          栈空 → 数字栈[-2], 运算符栈['*']
          cur = 0
i=10: '5' → cur = 5
i=11: 越界，循环结束
push(5, '+') → 栈顶是 '*'
              立即计算: -2 * 5 = -10
              数字栈[-10], 运算符栈['+']
where = 11
compute: -10
返回 -10
```

## 五、经验总结
### 5.1 设计模式
**1. 递归处理嵌套结构**
- 适用场景：括号匹配、树形结构、分治问题
- 关键：确定递归终止条件和返回值含义
**2. 全局变量传递额外状态**
- 适用场景：需要返回多个值，或跨层级共享状态
- 注意：确保线程安全（本题单线程无问题）
**3. 双栈处理运算符优先级**
- 数字栈 + 运算符栈分离
- 高优先级立即归约，低优先级延迟处理
### 5.2 易错点
**1. 忘记处理最后一个数字**
- 错误：循环结束直接 compute
- 正确：先 push 最后一个数字，再 compute
**2. 递归返回后未更新索引**
- 错误：直接使用原来的 i 继续
- 正确：i = where + 1
**3. 乘除未立即计算**
- 错误：所有运算符都入栈，最后统一计算
- 正确：遇到乘除立即与栈顶计算
**4. 边界条件遗漏**
- 空字符串
- 只有括号
- 括号不匹配（题目保证合法，但实际要考虑）
### 5.3 复杂度分析
| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个字符处理一次，push/compute 均摊 O(1) |
| 空间 | O(n) | 递归栈深度 O(n)，双栈空间 O(n) |

### 5.5 扩展思考
**1. 如何处理负数？**
- 当前代码只处理非负整数
- 支持负数：在解析数字前检查 `-` 号，作为一元运算符处理
**2. 如何处理空格？**
- 当前代码未处理空格
- 解决方案：遇到空格直接跳过
**3. 如何支持浮点数？**
- 记录小数点位置
- 或使用 BigDecimal 处理精度
**4. 如何优化空间？**
- 用数组代替 List，减少装箱拆箱开销
- 但代码可读性会降低

## 六、代码模板
```java
public class Solution {
    private int where;  // 实例变量，避免静态变量线程安全问题
    
    public int calculate(String s) {
        where = 0;
        return f(s.toCharArray(), 0);
    }
    
    private int f(char[] s, int i) {
        Deque<Integer> numbers = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();
        int cur = 0;
        
        while (i < s.length && s[i] != ')') {
            if (Character.isDigit(s[i])) {
                cur = cur * 10 + (s[i++] - '0');
            } else if (s[i] == '(') {
                cur = f(s, i + 1);
                i = where + 1;
            } else {
                push(numbers, ops, cur, s[i++]);
                cur = 0;
            }
        }
        
        push(numbers, ops, cur, '+');
        where = i;
        return compute(numbers, ops);
    }
    
    private void push(Deque<Integer> numbers, Deque<Character> ops, int cur, char op) {
        if (ops.isEmpty() || ops.peek() == '+' || ops.peek() == '-') {
            numbers.push(cur);
            ops.push(op);
        } else {
            int top = numbers.pop();
            char topOp = ops.pop();
            numbers.push(topOp == '*' ? top * cur : top / cur);
            ops.push(op);
        }
    }
    
    private int compute(Deque<Integer> numbers, Deque<Character> ops) {
        // 注意：栈是 LIFO，需要倒序处理
        // 或者使用 LinkedList 按顺序操作
        int ans = 0;
        while (!numbers.isEmpty()) {
            int num = numbers.pollLast();  // 从尾部取，保持顺序
            char op = ops.isEmpty() ? '+' : ops.pollLast();
            ans = op == '+' ? ans + num : ans - num;
        }
        return ans;
    }
}
```
