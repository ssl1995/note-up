# 马拉车算法（Manacher）详解——LC5 最长回文子串
## 算法简介
马拉车算法（Manacher's Algorithm）由 Glenn Manacher 于 1975 年提出，用于在 **O(n)** 时间内求出字符串的每个位置为中心的最长回文半径，从而求出最长回文子串。对比暴力法 O(n³) 和中心扩展法 O(n²)，它通过复用已计算的信息，做到每个位置的字符最多被"无效比较"常数次，是回文类问题的经典优化解法，也是面试中的加分项。
## 核心思想三要素
| 要素 | 含义 | 作用 |
| ---- | ---- | ---- |
| 预处理串 cs | 在原串每个字符之间及首尾插入 `#` | 统一奇偶回文的中心 |
| pArr[i] | 以 cs[i] 为中心的最长回文半径（包含自身） | 记录每个位置的回文信息 |
| pR / index | 所有回文右边界中最靠右的边界的"下一个位置" / 取得该边界时的回文中心 | 提供加速优化的依据 |
## 第一步：预处理——插入 `#` 统一奇偶中心
回文长度分奇偶两种情况，中心扩展时处理逻辑不同：
- 奇数回文 `aba`：中心是一个字符 `b`
- 偶数回文 `abba`：中心是两个字符之间的空隙
插入 `#` 后，偶数回文的中心也落在了某个 `#` 上，两种情况统一为"以一个位置为中心向外扩"：
- `s = "cabac"` → `cs = [#c#a#b#a#c#]`，长度从 `n` 变为 `2n + 1`
- `s = "abba"` → `cs = [#a#b#b#a#]`，偶数回文 `abba` 的中心落在中间的 `#` 上，半径为 5
**重要结论**：预处理串中每个回文都是奇数长度，半径 `pArr[i]` 与原串回文长度满足关系：`原串回文长度 = pArr[i] - 1`。
## 第二步：pArr、pR、index 三个核心变量
以 `cs = [#c#a#b#a#c#]` 为例：
- `pArr = [1,2,1,2,1,6,1,2,1,2,1]`，`pArr[5]=6` 表示以 `b` 为中心的回文 `c#a#b#a#c` 半径为 6
- `pR`：遍历过程中所有回文最右到达位置的**下一个位置**，初始为 -1，单调递增，只增不减
- `index`：最近一次让 `pR` 更新的回文中心位置
## 第三步：加速的关键——利用对称性复用结果
遍历到位置 `i` 时，分两种情况：
### 情况1：`i >= pR`（i 在最右回文边界之外）
之前的信息完全用不上，只能老老实实从半径 1 开始向外扩展：
```
pArr[i] = 1
```
### 情况2：`i < pR`（i 在已知回文边界内）
设 `i'` 是 `i` 关于 `index` 的对称点：`i' = 2 * index - i`。
由于 `[index 的左边界, pR)` 这一整段是回文的，所以 `i` 处的回文和 `i'` 处的回文有对称关系，可以复用 `pArr[i']`：
```
pArr[i] = Math.min(pArr[2 * index - i], pR - i)
```
取最小值的两种子情况：
- **子情况A：`i'` 的回文完全在 `index` 的回文内部** → `pArr[i'] < pR - i`，则 `pArr[i] = pArr[i']`，**不需要再向外扩，直接确定**
- **子情况B：`i'` 的回文超出或贴着 `index` 的回文边界** → `pArr[i'] >= pR - i`，则 `pArr[i]` 至少为 `pR - i`，**但还要继续向外扩**，因为 `pR` 之外的区域还是未知的
无论哪种情况，`pArr[i]` 都可以先直接赋一个保底值，再尝试外扩，这就是一句核心代码：
```java
pArr[i] = pR > i ? Math.min(pArr[2 * index - i], pR - i) : 1;
```
## 完整算法流程
- 第一步：把原串 `s` 变成预处理串 `cs`（`manacherString`）
- 第二步：从左到右遍历 `cs`，对每个位置 `i`：
  - 第一步：根据 `i` 与 `pR` 的关系，给 `pArr[i]` 一个保底值（加速的核心）
  - 第二步：从保底值出发尝试向外扩，扩不动就停
  - 第三步：如果 `i + pArr[i] > pR`，更新 `pR = i + pArr[i]`，`index = i`
  - 第四步：同步记录最大半径 `maxLen` 及其中心 `centerIndex`
- 第三步：把预处理串中的结果换算回原串坐标：
  - 最长回文长度：`maxLen - 1`
  - 原串中心：`(centerIndex - 1) / 2`
  - 原串起始下标：`begin = 中心 - (maxLen - 1 - 1) / 2`（代码中统一为 `centerIndex - (maxLen - 1) / 2`，其中 maxLen 已减过 1）
- 第四步：`s.substring(begin, begin + 原串最长回文长度)` 即为答案
## 代码实现（Solution4.java）
```java
public class Solution4 {
    public String longestPalindrome(String s) {
        if (s.length() < 2) {
            return s;
        }
        int len = s.length();
        // 将s转换为加了特殊字符#的字符数组，统一奇偶回文中心的差异性
        // 比如：s="cabac" 转化为 cs=[#c#a#b#a#c#]
        char[] cs = manacherString(s, len);
        // pArr[i]：以cs[i]为中心的最大回文半径
        int[] pArr = new int[cs.length];
        // pR：所有回文右边界中最靠右的那个的"下一个位置"，单调递增
        int pR = -1;
        // index：最近一次更新pR时的回文中心位置
        int index = -1;
        // 记录最大回文半径及其中心
        int maxLen = Integer.MIN_VALUE;
        int centerIndex = Integer.MIN_VALUE;
        int begin = 0;
        for (int i = 0; i != cs.length; i++) {
            // 加速核心：i在pR内则复用对称点i'=2*index-i的结果，取min保底；否则从半径1开始
            pArr[i] = pR > i ? Math.min(pArr[2 * index - i], pR - i) : 1;
            // 从保底半径继续尝试向外扩展
            while (i + pArr[i] < cs.length && i - pArr[i] >= 0) {
                if (cs[i + pArr[i]] == cs[i - pArr[i]]) {
                    pArr[i]++;
                } else {
                    break;
                }
            }
            // 如果i的回文右边界超过了pR，更新pR和index
            if (i + pArr[i] > pR) {
                pR = i + pArr[i];
                index = i;
            }
            // 更新最大回文半径和对应中心
            if (pArr[i] > maxLen) {
                maxLen = pArr[i];
                centerIndex = i;
            }
        }
        // 换算回原串：原串最长回文长度 = 预处理串半径 - 1
        maxLen = maxLen - 1;
        // 原串中心坐标：(预处理串中心 - 1) / 2
        centerIndex = (centerIndex - 1) / 2;
        // 统一奇偶两种情况的begin计算：中心 - (长度-1)/2
        begin = centerIndex - (maxLen - 1) / 2;
        return s.substring(begin, begin + maxLen);
    }

    // 将str转换成带#号的字符数组：长度 n -> 2n+1，偶数位放#，奇数位放原字符
    public static char[] manacherString(String s, int n) {
        char[] charArr = s.toCharArray();
        int index = 0;
        char[] res = new char[n * 2 + 1];
        for (int i = 0; i != res.length; i++) {
            res[i] = (i & 1) == 0 ? '#' : charArr[index++];
        }
        return res;
    }
}
```
## 为什么时间复杂度是 O(n)
关键在于 `pR` 是**单调递增**的：
- 每次向外扩展成功，`pR` 至少增加 1
- `pR` 最多从 -1 增加到 `cs.length`（即 `2n+1`）
- 所以所有位置的扩展操作加起来不超过 `O(n)` 次
- 其他操作（求保底值、更新答案）都是 O(1)
总复杂度：时间 O(n)，空间 O(n)。
## 图解示例：cs = [#c#a#b#a#c#]
- i=0：`i >= pR`，从1扩，`pArr[0]=1`，`pR=1, index=0`
- i=1：`i < pR`？不成立（pR=1 不大于1），从1扩，扩到 `pArr[1]=2`，`pR=3, index=1`
- i=2：`i < pR`，对称点 `i'=0`，`min(pArr[0], 3-2)=1`，扩不动，`pArr[2]=1`
- i=3：`i < pR`？不成立，从1扩到2，`pR=5, index=3`
- i=4：`i < pR`，对称点 `i'=2`，`min(pArr[2], 5-4)=1`，扩不动
- i=5：`i < pR`？不成立，从1一路扩到6（整个串都是回文），`pR=11, index=5`
- i=6~10：都在 pR 内，直接取对称点结果的 min 值，均扩不动
最终 `pArr` 最大值 6 在 index=5（字符 `b`），原串最长回文长度 = 6-1 = 5，即 `cabac`。
## 易错点提醒
- 易错点1：`pR` 的定义是回文右边界的**下一个位置**，判断条件是 `i + pArr[i] > pR`，不是 `>=`
- 易错点2：对称点公式是 `2 * index - i`，因为 `index` 是 `i` 与 `i'` 的中点
- 易错点3：取 `min` 的两个值缺一不可，`pArr[i']` 提供复用信息，`pR - i` 提供边界约束
- 易错点4：预处理串下标换原串下标是 `(centerIndex - 1) / 2`，而不是 `/2`
- 易错点5：原串回文长度是 `pArr[i] - 1`，不是 `pArr[i]`（因为插入的 `#` 也算进半径里了）
## 与其他解法对比
| 解法 | 思路 | 时间复杂度 | 空间复杂度 |
| ---- | ---- | ---------- | ---------- |
| 暴力法 | 枚举所有子串再验证回文 | O(n³) | O(1) |
| 中心扩展 | 枚举每个中心向两边扩 | O(n²) | O(1) |
| 动态规划 | dp[i][j] 表示 s[i..j] 是否回文 | O(n²) | O(n²) |
| 马拉车 | 插入#统一奇偶 + 对称复用加速 | **O(n)** | O(n) |
## 记忆口诀
一插井号统一奇偶，二记半径pArr，三靠pR和index对称复用，四做min保底再外扩，五把半径减一还原原串。
## 核心知识点
- 预处理插入分隔符统一奇偶回文中心
- 回文半径数组 + 最右回文边界的单调性
- 对称点复用（`min(pArr[2*index-i], pR-i)`）实现 O(n) 加速
- 预处理串与原串的坐标/长度换算
