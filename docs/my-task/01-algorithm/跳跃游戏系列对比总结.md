# 跳跃游戏 I / II / III 对比总结

## 一句话定位

| 题目 | 核心问题 | 本质 |
|---|---|---|
| LC55 跳跃游戏 I | 能否到达最后一个下标？ | 贪心：维护最远可达距离 |
| LC45 跳跃游戏 II | 到达最后一个下标的最少跳跃次数？ | 贪心：维护当前跳跃边界 + 最远可达 |
| LC1306 跳跃游戏 III | 能否到达值为 0 的任意下标？ | 图搜索：BFS/DFS |

---

## 关键差异对比表

| 维度 | LC55 | LC45 | LC1306 |
|---|---|---|---|
| **跳跃方向** | 只能向前 | 只能向前 | 可向前 / 向后 |
| **跳跃距离** | 0 ~ nums[i] 任意选 | 0 ~ nums[i] 任意选 | 固定等于 arr[i] |
| **问题目标** | 判断可行性 | 求最小跳跃次数 | 判断能否到达目标值 |
| **适用算法** | 贪心 | 贪心 | BFS / DFS / 并查集 |
| **时间复杂度** | O(n) | O(n) | O(n) |
| **空间复杂度** | O(1) | O(1) | O(n) |
| **是否保证可达** | 否 | 是 | 否 |

---

## 为什么 I 和 II 能用贪心，III 不能？

### I / II 能贪心的原因
- 只能向前跳，后面的位置不会反过来影响前面。
- 每个位置能跳的“范围”是连续的 `[i, i + nums[i]]`。
- 只要维护“当前能到达的最远位置”，就能覆盖所有可能。

### III 必须用图搜索的原因
- 可以向后跳，形成回路（例如 `arr[i] = 1` 时，可以在 i 和 i+1 之间来回跳）。
- 每次跳跃距离固定，不能自由选择步数。
- 目标不是“最后一个下标”，而是“任意值为 0 的下标”，位置不固定。

## 算法选择决策树

```
看到"跳跃游戏"类题目
    │
    ├─ 只能向前跳？
    │       │
    │       ├─ 问"能不能到" → LC55 → 贪心（最远可达）
    │       │
    │       └─ 问"最少几次" → LC45 → 贪心（当前边界 + 最远可达）
    │
    └─ 能左右跳？
            │
            └─ 问"能否到达某类位置" → LC1306 → BFS/DFS
```

## 代码模板对比

### LC55：能否到达末尾

```java
public boolean canJump(int[] nums) {
    int maxReach = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > maxReach) return false;     // 当前位置不可达
        maxReach = Math.max(maxReach, i + nums[i]);
        if (maxReach >= nums.length - 1) return true;
    }
    return false;
}
```

### LC45：最少跳跃次数

```java
public int jump(int[] nums) {
    int maxReach = 0;   // 当前能到达的最远位置
    int end = 0;        // 当前这一跳的边界
    int jumps = 0;      // 跳跃次数

    for (int i = 0; i < nums.length - 1; i++) {
        maxReach = Math.max(maxReach, i + nums[i]);
        if (i == end) {         // 走到当前跳跃边界，必须再跳一次
            end = maxReach;
            jumps++;
        }
    }
    return jumps;
}
```

### LC1306：能否到达值为 0 的下标

```java
public boolean canReach(int[] arr, int start) {
    int n = arr.length;
    boolean[] visited = new boolean[n];
    Queue<Integer> queue = new LinkedList<>();
    queue.offer(start);
    visited[start] = true;

    while (!queue.isEmpty()) {
        int i = queue.poll();
        if (arr[i] == 0) return true;

        int right = i + arr[i];
        if (right < n && !visited[right]) {
            visited[right] = true;
            queue.offer(right);
        }
        int left = i - arr[i];
        if (left >= 0 && !visited[left]) {
            visited[left] = true;
            queue.offer(left);
        }
    }
    return false;
}
```

## 面试中快速判断的要点

### 第一步：看方向
- 只能向前 → 考虑贪心
- 能左右 → 考虑图搜索

### 第二步：看问题类型
- “能不能到” → 可行性（LC55 / LC1306）
- “最少几次” → 最优化（LC45）

### 第三步：看约束
- 范围连续且单向 → 贪心大概率适用
- 固定步长、可回退、目标不固定 → 必须用 BFS/DFS

---

## 常见误区

| 误区 | 正确理解 |
|---|---|
| 三道题都用贪心 | 只有 I 和 II 能贪心，III 是图搜索 |
| LC45 用 DP 一定更好 | DP O(n²) 不如贪心 O(n)，贪心才是最优解 |
| LC1306 不用 visited | 不标记访问会形成死循环，例如 arr[i] = 1 时来回跳 |
| BFS 和 DFS 在 LC1306 复杂度不同 | 都是 O(n)，BFS 更直观，DFS 代码更短 |

## 复习建议

1. **先默写 LC55**：训练“最远可达”这个核心思想。
2. **再默写 LC45**：重点理解 `end` 边界和 `maxReach` 的区别。
3. **最后做 LC1306**：刻意练习“看到能左右跳就想到图搜索”的反射。
4. 面试时如果面试官连续出这三道，要第一时间点出 **方向** 和 **步长是否固定** 这两个区分点。
