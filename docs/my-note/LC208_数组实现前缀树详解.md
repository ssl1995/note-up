# 数组实现前缀树（Trie）详解
## 一、核心思想
前缀树（字典树）是一种用于高效存储和检索字符串集合的数据结构。本实现采用**静态数组**方式，通过整数编号代替对象引用，将树结构压缩到二维数组中，适合笔试和面试场景。
## 二、数据结构定义
```java
private final int MAX = 150001;           // 最大节点数
private final int[][] tree = new int[MAX][26];  // 存储子节点编号
private final int[] pass = new int[MAX];        // 经过该节点的字符串数量
private final int[] end = new int[MAX];         // 以该节点结尾的字符串数量
private int cnt;                                 // 当前已分配的最大节点编号
```
| 数组 | 含义 | 示例说明 |
|------|------|----------|
| `tree[cur][path]` | 节点 `cur` 的第 `path` 个子节点编号 | `tree[1][0]=2` 表示节点1的'a'子节点是节点2 |
| `pass[cur]` | 有多少个字符串经过节点 `cur` | 用于 `startsWith` 判断前缀是否存在 |
| `end[cur]` | 有多少个字符串在节点 `cur` 结束 | 用于 `search` 判断完整单词是否存在 |
| `cnt` | 节点编号计数器，从1开始 | 0号位置弃用，作为"空"标识 |
## 三、插入字符串 "abcd" 过程详解
### 初始状态
```
cnt = 1
tree 全为 0
pass 全为 0
end 全为 0
```
### 插入步骤
**第1步：从根节点出发**
```
cur = 1
pass[1]++  →  pass[1] = 1
```
**第2步：处理字符 'a'（path = 0）**
```
tree[1][0] == 0，说明没有 'a' 子节点
tree[1][0] = ++cnt = 2  （创建新节点2）
cur = 2
pass[2]++  →  pass[2] = 1
```
**第3步：处理字符 'b'（path = 1）**
```
tree[2][1] == 0，说明没有 'b' 子节点
tree[2][1] = ++cnt = 3  （创建新节点3）
cur = 3
pass[3]++  →  pass[3] = 1
```
**第4步：处理字符 'c'（path = 2）**
```
tree[3][2] == 0，说明没有 'c' 子节点
tree[3][2] = ++cnt = 4  （创建新节点4）
cur = 4
pass[4]++  →  pass[4] = 1
```
**第5步：处理字符 'd'（path = 3）**
```
tree[4][3] == 0，说明没有 'd' 子节点
tree[4][3] = ++cnt = 5  （创建新节点5）
cur = 5
pass[5]++  →  pass[5] = 1
```
**第6步：标记单词结尾**
```
end[5]++  →  end[5] = 1
```
### 插入完成后的树结构
```
节点编号:  1    2    3    4    5
字符:     根    a    b    c    d
pass:    [1]  [1]  [1]  [1]  [1]
end:     [0]  [0]  [0]  [0]  [1]

tree 数组关键值:
tree[1][0] = 2   (根 --a--> 节点2)
tree[2][1] = 3   (节点2 --b--> 节点3)
tree[3][2] = 4   (节点3 --c--> 节点4)
tree[4][3] = 5   (节点4 --d--> 节点5)
```

## 四、关键设计说明
### 1. 为什么节点编号从1开始？
- **0作为空标识**：`tree[cur][path] == 0` 表示该子节点不存在
- 如果从0开始，无法区分"节点0"和"空"
### 2. `pass` 和 `end` 的区别
| 场景 | `pass` 作用 | `end` 作用 |
|------|------------|-----------|
| `search("abcd")` | 不使用 | `end[5] > 0` 才返回 true |
| `startsWith("ab")` | `pass[3] > 0` 即可返回 true | 不使用 |
| `delete("abcd")` | 沿途减1，为0则断开链接 | 结尾减1 |
### 3. 删除操作的巧妙之处
```java
if (--pass[tree[cur][path]] == 0) {
    tree[cur][path] = 0;  // 断开链接，后续节点自动回收
    return;
}
```
- 当某个子节点的 `pass` 减为0时，说明没有其他字符串经过该节点
- 直接断开父节点到该子节点的链接，后续节点自然失效，无需逐个清理
## 五、复杂度分析
| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `insert` | O(L) | L为字符串长度 |
| `search` | O(L) | L为字符串长度 |
| `startsWith` | O(L) | L为前缀长度 |
| `delete` | O(L) | L为字符串长度 |
| 空间 | O(MAX×26) | 静态数组，与字符串数量无关 |
## 六、适用场景
- ✅ 笔试、面试（代码简洁，无需定义节点类）
- ✅ 字符串集合的存储与前缀匹配
- ❌ 工程实践（静态数组浪费空间，应使用动态节点）
