# 二维前缀和与二维差分数组总结
> 参考题目：LC2132 用邮票贴满网格图（前缀和 + 差分 组合拳的典型题）
## 一、三者关系（原始数组 / 前缀和数组 / 差分数组）
设原始数组为 `grid[m][n]`（0-based）。
- **前缀和数组 sum**：`sum[i][j]` = 原数组中 `(0,0)` 到 `(i-1,j-1)` 这个矩形区域的元素总和（1-based 定义，整体向右下偏移一格）。
- **差分数组 diff**：是原数组的"增量记录"。**对 diff 求前缀和，就还原出原数组**。即 diff 和 sum 是互逆关系：`前缀和(差分(数组)) = 数组`。
- 一句话记忆：**前缀和是"积分"，差分是"导数"**，求前缀和与求差分互为逆运算。
| 数组 | 含义 | 擅长的事 |
| --- | --- | --- |
| 原始数组 grid | 每个格子的值 | 直接读写单点 |
| 前缀和 sum | (0,0)~(i-1,j-1) 的区域和 | **多次查询**任意矩形区域和，O(1)/次 |
| 差分 diff | 区域修改的增量记录 | **多次批量修改**矩形区域（统一 +v），O(1)/次 |
## 二、初始化长度与初始值
| 数组 | 初始化长度 | 初始值 | 原因 |
| --- | --- | --- | --- |
| sum | `new int[m + 1][n + 1]` | 全 0（Java 默认） | 多出的第 0 行、第 0 列作**哨兵**，查询 `sum[a-1][d]`、`sum[c][b-1]` 时不用特判 a=1 或 b=1 的边界 |
| diff | `new int[m + 2][n + 2]` | 全 0（Java 默认） | add 操作会访问 `c+1`、`d+1`；当区域顶到边界（c=m, d=n）时，下标最大到 `m+1`、`n+1`，所以要比 sum **再多开一行一列** |
**易错点**：diff 只开 `m+1` 会数组越界！`c+1` 最大可达 `m+1`，所以长度必须是 `m+2`。
## 三、核心公式
以下 `a,b,c,d` 均为 **1-based** 坐标，`(a,b)` 为左上角，`(c,d)` 为右下角。
### 1. 构建前缀和（容斥原理）
```
sum[i][j] = grid[i-1][j-1] + sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1]
```
含义：当前格子值 + 上方区域和 + 左方区域和 − 左上重复计算的区域和。
```java
// 先填入原数组（偏移一格），再累加
for (int i = 0; i < m; i++)
  for (int j = 0; j < n; j++)
    sum[i + 1][j + 1] = grid[i][j];
build(sum);
```
```java
void build(int[][] nums) {
  for (int i = 1; i < nums.length; i++)
    for (int j = 1; j < nums[0].length; j++)
      nums[i][j] += nums[i - 1][j] + nums[i][j - 1] - nums[i - 1][j - 1];
}
```
### 2. 前缀和查询区域和
查询 `(a,b)` 到 `(c,d)` 的区域和（**大矩形减两块、加回重复减的角**）：
```
regionSum = sum[c][d] - sum[a-1][d] - sum[c][b-1] + sum[a-1][b-1]
```
```java
int getRegionSum(int[][] sum, int a, int b, int c, int d) {
  return sum[c][d] - sum[c][b - 1] - sum[a - 1][d] + sum[a - 1][b - 1];
}
```
**记忆口诀**：右下角 − 上方的 − 左方的 + 左上角（加回重复减掉的）。
**易错点**：减的是 `sum[a-1][d]` 和 `sum[c][b-1]`，行列别写反；加回来的是 `sum[a-1][b-1]`，两个都减 1。
### 3. 差分区域修改
给 `(a,b)` 到 `(c,d)` 的整个区域统一 `+v`，只动 **4 个角**：
```
diff[a][b]     += v;   // 左上角：+
diff[c+1][b]   -= v;   // 下边界的下一行：−
diff[a][d+1]   -= v;   // 右边界的下一列：−
diff[c+1][d+1] += v;   // 右下角斜对角：+（补回多减的）
```
```java
void add(int[][] diff, int a, int b, int c, int d, int v) {
  diff[a][b] += v;
  diff[c + 1][b] -= v;
  diff[a][d + 1] -= v;
  diff[c + 1][d + 1] += v;
}
```
**记忆口诀**：**左上加、右下加，另外两个减**（与查询区域和的符号规律正好呼应）。
### 4. 差分还原原数组
所有 add 操作完成后，**对 diff 求一遍前缀和（复用同一个 build 函数）**，`diff[i][j]` 就变成原数组 `(i-1,j-1)` 位置的最终值：
```java
build(diff); // 求前缀和即还原
// 原数组 grid[i][j] 的最终值 = diff[i+1][j+1]
```
## 四、怎么选：前缀和 vs 差分
- **查询多、修改少**（静态数组反复查区域和）→ 用**前缀和**。如 LC304 二维区域和检索。
- **修改多、最后统一查**（反复给区域 +v，最后问每个格子的值）→ 用**差分**。如 LC2132 贴邮票、LC1109 航班预订（一维差分）。
- **既要查又要批量改**（先查询做判断、再批量打标记）→ **两个一起用**，如 LC2132：先用前缀和判断区域是否全 0，再用差分给可贴区域打标记，最后还原差分数组检查每个格子。
## 五、LC2132 完整套路（组合拳模板）
```java
public boolean possibleToStamp(int[][] grid, int stampHeight, int stampWidth) {
  int m = grid.length, n = grid[0].length;
  // 1. 前缀和：O(1) 查询任意 stampHeight × stampWidth 区域是否全 0（可贴）
  int[][] sum = new int[m + 1][n + 1];
  for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
      sum[i + 1][j + 1] = grid[i][j];
  build(sum);
  // 2. 差分：枚举邮票所有可放的左上角，能贴就给整个区域 +v
  int[][] diff = new int[m + 2][n + 2];
  for (int a = 1, c = a + stampHeight - 1; c <= m; a++, c++)
    for (int b = 1, d = b + stampWidth - 1; d <= n; b++, d++)
      if (getRegionSum(sum, a, b, c, d) == 0)
        add(diff, a, b, c, d, 2); // v 用 2，避免和 grid 里的 1 混淆
  build(diff); // 还原：diff[i+1][j+1] 即为格子 (i,j) 被邮票覆盖的次数
  // 3. 校验：空格(0)却没被任何邮票覆盖 → 失败
  for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
      if (grid[i][j] == 0 && diff[i + 1][j + 1] == 0)
        return false;
  return true;
}
```
## 六、易错点清单（避坑速查）
1. **下标基准**：sum/diff 全部用 **1-based** 思维，原数组是 0-based，转换时 `grid[i][j] ↔ sum[i+1][j+1]`，别混用。
2. **长度**：sum 开 `m+1`，diff 开 `m+2`，差分多一行一列给 `c+1`、`d+1` 留位置。
3. **初始值**：全部靠 Java 默认的 0，**不要**手动填别的值；第 0 行第 0 列是哨兵，build 时从下标 1 开始。
4. **build 起点**：`for (int i = 1; ...)`，从 1 开始，不能从 0 开始（会访问 -1 越界）。
5. **查询公式**：减 `a-1` 行、减 `b-1` 列、加回 `(a-1, b-1)`；行列别写反。
6. **add 四角符号**：左上加、右下加、其余两个减；和查询公式"减两块加回角"的规律一致。
7. **差分必须最后 build 一次**：add 完直接读 diff 是错的，还原后才能当原数组用。
8. **build 函数通用**：同一个 `build`（前缀和累加）既能构建 sum，也能还原 diff，因为差分还原 = 求前缀和。
