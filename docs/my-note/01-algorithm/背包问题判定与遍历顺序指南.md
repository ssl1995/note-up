# 背包问题判定与遍历顺序指南
## 一、怎么判断是背包问题？
### 1. 背包问题的核心特征
当题目同时满足以下特征时，大概率是背包问题：
| 特征 | 说明 | 典型问法 |
|------|------|----------|
| **有容量限制** | 存在一个"背包"容量/目标和 | 和为 target、不超过 capacity、装满背包 |
| **有物品集合** | 有一组物品可供选择 | 数组 nums、硬币 coins、单词列表 |
| **每个物品有属性** | 重量/体积/价值/数字大小 | nums[i]、coins[i] |
| **求最值/方案数/可行性** | 最大价值、最少数量、能否凑成 | 最多/最少/是否存在/有多少种 |
### 2. 常见背包问题变形识别
| 题目类型 | 背包模型 | 物品 | 容量 | 目标 |
|----------|----------|------|------|------|
| **LC416 分割等和子集** | 01背包 | nums[i] | sum/2 | 能否装满 |
| **LC494 目标和** | 01背包 | nums[i] | (sum+target)/2 | 方案数 |
| **LC322 零钱兑换** | 完全背包 | coins[i] | amount | 最少硬币数 |
| **LC518 零钱兑换 II** | 完全背包 | coins[i] | amount | 组合数 |
| **LC377 组合总和 IV** | 完全背包 | nums[i] | target | 排列数 |
| **LC139 单词拆分** | 完全背包 | 单词 | 字符串长度 | 能否拼成 |
| **LC279 完全平方数** | 完全背包 | 平方数 | n | 最少数量 |
| **LC1049 最后一块石头的重量 II** | 01背包 | stones[i] | sum/2 | 最小差值 |
| **LC474 一和零** | 二维01背包 | 字符串 | m个0, n个1 | 最大子集大小 |
### 3. 快速判断口诀
> **"给一堆东西，有容量限制，求最值/方案/可行性"** → 背包问题
---
## 二、01背包 vs 完全背包：核心区别
### 1. 一句话区分
| 类型 | 物品使用次数 | 关键特征 |
|------|-------------|----------|
| **01背包** | 每个物品**最多用一次** | 选或不选 |
| **完全背包** | 每个物品**可以无限次使用** | 可以重复选 |
### 2. 题目中的信号词
**01背包信号：**
- "每个元素只能用一次"
- "分割成两个子集"
- "从数组中选取若干个数"
- 数组中的元素本身不可重复
**完全背包信号：**
- "硬币可以重复使用"
- "每种面额的硬币有无限个"
- "可以重复使用数组中的元素"
- 物品是"种类"概念，不是具体个体

## 三、两个 for 循环怎么写？（核心难点）
### 0. 遍历顺序的本质规律
**核心观察**：外层循环遍历的是"条件给的确定数组"（物品），内层循环遍历的是"待确定的动态规划数组"（容量）。
| 背包类型 | 外层 | 内层 | 能否交换 |
|----------|------|------|----------|
| **01背包** | 物品（确定数组） | 容量（dp数组） | **不能交换** |
| **完全背包** | 物品（确定数组） | 容量（dp数组） | **可以交换** |
**为什么完全背包可以交换？**
完全背包中，无论外层是物品还是容量，每个状态 `dp[j]` 都会被正确更新，因为：
- 物品可以重复选择，不存在"顺序依赖"问题
- 两种写法最终都会遍历所有 (物品, 容量) 组合
**为什么01背包不能交换？**
01背包要求每个物品只选一次，必须保证：
- 外层固定一个物品，内层更新所有容量
- 这样 `dp[j-w[i]]` 才是"未选过当前物品"的旧状态
- 如果交换，外层容量内层物品，同一容量会尝试所有物品，变成完全背包
### 1. 标准模板对比
#### 01背包（一维数组优化）
```java
// 外层：遍历物品（每个物品只处理一次）
for (int i = 0; i < n; i++) {
    // 内层：倒序遍历容量（从大到小）
    for (int j = C; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```
#### 完全背包（一维数组）
```java
// 外层：遍历物品
for (int i = 0; i < n; i++) {
    // 内层：正序遍历容量（从小到大）
    for (int j = w[i]; j <= C; j++) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```
### 2. 为什么 01背包要倒序？完全背包要正序？
#### 01背包倒序的原因
**正序的问题（错误示范）：**
```java
// 错误：正序遍历
for (int j = w[i]; j <= C; j++) {
    dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
}
```
假设 `w[i]=3, v[i]=5`，容量 `C=6`：
- `j=3`: `dp[3] = max(dp[3], dp[0]+5) = 5`（选了物品i）
- `j=6`: `dp[6] = max(dp[6], dp[3]+5) = 10`（又选了一次物品i！）
**问题**：`dp[3]` 已经被更新过了，再用它来更新 `dp[6]` 相当于物品 i 被选了两次。
**倒序的正确性：**
```java
// 正确：倒序遍历
for (int j = C; j >= w[i]; j--) {
    dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
}
```
- `j=6`: `dp[6] = max(dp[6], dp[3]+5)`，此时 `dp[3]` 还是**上一轮的旧值**（没选过物品i）
- `j=3`: `dp[3] = max(dp[3], dp[0]+5) = 5`
**核心**：倒序保证 `dp[j-w[i]]` 是**未考虑当前物品**的状态。
#### 完全背包正序的原因
完全背包**允许重复选择**，所以：
- `dp[j-w[i]]` 应该包含**已经考虑过当前物品**的状态
- 正序遍历正好满足这个需求：先更新小的 `j`，再用更新后的值去更新大的 `j`
### 3. 记忆技巧
| 背包类型 | 遍历方向 | 记忆口诀 |
|----------|----------|----------|
| 01背包 | **倒序** | "01倒序，避免重复" |
| 完全背包 | **正序** | "完全正序，允许重复" |
或者：
> **01背包：从大到小，每个只用一次**
> **完全背包：从小到大，可以反复用**
### 4. 完全背包的两种等价写法
以 LC322 零钱兑换为例：
**写法A：外层容量，内层物品（coinChange1）**
```java
for (int i = 1; i <= amount; i++) {
    for (int coin : coins) {
        if (i >= coin) {
            dp[i] = Math.min(dp[i], dp[i - coin] + 1);
        }
    }
}
```
**写法B：外层物品，内层容量（coinChange2）**
```java
for (int coin : coins) {
    for (int i = 1; i <= amount; i++) {
        if (i >= coin) {
            dp[i] = Math.min(dp[i], dp[i - coin] + 1);
        }
    }
}
```
**结论**：完全背包两种写法等价，因为物品可重复，无顺序依赖。

## 四、常见错误与避坑指南
### 错误1：01背包写成完全背包（LC416 典型错误）
**错误代码：**
```java
// 错误：外层容量，内层物品 → 变成完全背包
for (int i = target; i >= 0; i--) {
    for (int num : nums) {
        if (i - num >= 0) {
            dp[i] = dp[i] || dp[i - num];
        }
    }
}
```
**问题**：对于每个容量 `i`，都尝试所有物品，相当于物品可以重复选。
**正确代码：**
```java
// 正确：外层物品，内层容量倒序
for (int num : nums) {
    for (int j = target; j >= num; j--) {
        dp[j] = dp[j] || dp[j - num];
    }
}
```
### 错误2：01背包正序遍历
**错误代码：**
```java
for (int num : nums) {
    for (int j = num; j <= target; j++) {  // 错误：正序
        dp[j] = dp[j] || dp[j - num];
    }
}
```
**问题**：`dp[j-num]` 可能已经被当前物品更新过，导致重复选择。
### 错误3：完全背包倒序遍历
**错误代码：**
```java
for (int coin : coins) {
    for (int i = amount; i >= coin; i--) {  // 错误：倒序
        dp[i] = Math.min(dp[i], dp[i - coin] + 1);
    }
}
```
**问题**：倒序导致 `dp[i-coin]` 是旧值，无法体现"重复选择"的特性。

## 五、二维 dp 与一维 dp 的关系
### 二维 dp（好理解，空间高）
```java
// dp[i][j]: 前 i 个物品，容量 j 时的最大价值
for (int i = 1; i <= n; i++) {
    for (int j = 0; j <= C; j++) {
        // 不选物品 i
        dp[i][j] = dp[i-1][j];
        // 选物品 i
        if (j >= w[i]) {
            dp[i][j] = max(dp[i][j], dp[i-1][j-w[i]] + v[i]);
        }
    }
}
```
### 一维 dp（空间优化，需倒序）
```java
// dp[j]: 容量 j 时的最大价值
for (int i = 0; i < n; i++) {
    for (int j = C; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
```
**关键点**：一维 dp 的 `dp[j]` 在更新前相当于二维的 `dp[i-1][j]`，更新后相当于 `dp[i][j]`。

## 六、实战演练：LC416 分割等和子集
### 问题分析
- **物品**：数组中的每个数字（只能用一次）→ 01背包
- **容量**：`target = sum / 2`
- **目标**：能否装满 → `dp[target]`
### 正确代码
```java
public boolean canPartition(int[] nums) {
    int sum = Arrays.stream(nums).sum();
    if ((sum & 1) == 1) return false;
    
    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    
    // 01背包：外层物品，内层容量倒序
    for (int num : nums) {
        for (int j = target; j >= num; j--) {
            dp[j] = dp[j] || dp[j - num];
        }
    }
    
    return dp[target];
}
```
### 错误代码对比
```java
// 错误：变成完全背包，[3,3,3,4,5]会误判为false
for (int i = target; i >= 0; i--) {
    for (int num : nums) {
        if (i - num >= 0) {
            dp[i] = dp[i] || dp[i - num];
        }
    }
}
```

## 七、总结速查表
| 维度 | 01背包 | 完全背包 |
|------|--------|----------|
| **物品次数** | 0或1次 | 无限次 |
| **外层循环** | 物品（必须） | 物品或容量（可交换） |
| **内层循环** | 容量倒序（必须） | 容量正序（通常） |
| **能否交换for** | **不能** | **可以** |
| **状态含义** | `dp[j]` = 容量j时的最优解 | 同左 |
| **典型题目** | LC416, LC494, LC1049 | LC322, LC518, LC377 |
| **记忆口诀** | 01倒序，避免重复 | 完全正序，允许重复 |

## 八、解题步骤 checklist
1. **判断是否是背包问题**：有容量限制？有物品集合？求最值/方案/可行性？
2. **判断01还是完全**：物品能重复选吗？
3. **确定 dp 含义**：`dp[j]` 表示什么？
4. **写状态转移方程**：选或不选？
5. **确定遍历顺序**：01倒序，完全正序
6. **初始化**：`dp[0]` 通常初始化为边界值
7. **返回结果**：通常是 `dp[target]`
