# LC438 与 LC76 对比总结

这两道题都是“两个字符串 + 滑动窗口 + 字符频次数组”的经典模型，但目标和约束不同，导致窗口行为差异很大。

## 1. 题目本质对比

| 维度 | LC438 找到字符串中所有字符异位词 | LC76 最小覆盖子串 |
| --- | --- | --- |
| **输入** | `s`（主串）、`p`（模式串） | `s`（主串）、`t`（目标串） |
| **目标** | 找到 `s` 中所有 `p` 的异位词子串 | 找到 `s` 中覆盖 `t` 所有字符的最短子串 |
| **窗口长度** | **固定**：必须等于 `p.length()` | **可变**：只要覆盖 `t` 即可，越短越好 |
| **匹配要求** | `s` 窗口内每种字符数量 **恰好等于** `p` | `s` 窗口内每种字符数量 **至少等于** `t`，允许多余字符 |
| **返回结果** | 所有合法子串的**起始下标列表** | **最短子串**本身（或空串） |
| **字符范围** | 仅小写字母 → `int[26]` | 全部 ASCII → `int[256]` |

## 2. 滑动窗口行为差异

### LC438：定长窗口，左边界每次只缩 1

```java
// 窗口超过 p 长度，缩小左边界
// 每轮 r 只前进 1 步，窗口最多比 n 大 1，缩一次即可，无需 while
if (r - l + 1 > n) {
    int leftIndex = s.charAt(l) - 'a';
    if (sMap[leftIndex] == pMap[leftIndex]) {
        sClassify--;
    }
    sMap[leftIndex]--;
    l++;
}
```

**核心特点**：
- 右指针每步前进 1，左指针也最多前进 1。
- 因为窗口长度必须固定为 `n`，所以用 `if` 即可，不需要 `while` 收缩。
- 不需要记录最短长度，只要长度恰好等于 `n` 且匹配就收集答案。

### LC76：变长窗口，左边界要尽量缩到不能缩

```java
if (debt == 0) {
    while (cnts[cs[l]] > 0) {
        cnts[cs[l++]]--;
    }
    if (r - l + 1 < len) {
        len = r - l + 1;
        start = l;
    }
}
```

**核心特点**：
- 窗口有效时（`debt == 0`），要不断从左边收缩，直到再缩就破坏覆盖为止。
- 必须用 `while`，因为可能连续多个字符都是多余的。
- 需要维护全局最短长度 `len` 和起始位置 `start`。

## 3. 计数逻辑差异

### LC438：维护两个频次数组，比较“种类匹配数”

```java
int[] sMap = new int[26];  // 当前窗口内各字符数量
int[] pMap = new int[26];  // p 中各字符数量
int pClassify = 0;         // p 中有多少种字符
int sClassify = 0;         // 当前窗口中有多少种字符恰好匹配 p
```

- `sMap[index] == pMap[index]` 时，说明该字符种类匹配成功，`sClassify++`。
- 窗口加入右边字符时先 `++` 再判断；移出左边字符时先判断再 `--`。
- 最终判断 `pClassify == sClassify`。

### LC76：维护一个频次数组 + “债务”思想

```java
int[] cnts = new int[256];
for (char c : ct) {
    cnts[c]--;     // 需要的字符用负数表示
}
int debt = ct.length;  // 总共还欠多少个字符
```

- `cnts[c] < 0` 表示还欠字符 `c`。
- 右指针遇到某个字符，如果 `cnts[c]++ < 0`，说明这个字符是刚需，`debt--`。
- `debt == 0` 表示所有字符都覆盖够了。
- 左指针收缩时，如果 `cnts[c] > 0`，说明该字符是多余的，可以 `--` 移出。

## 4. 记忆口诀

> **定长精确匹配 → LC438（异位词）**
>
> **变长覆盖最短 → LC76（最小覆盖子串）**

| 看到什么关键词 | 对应题目 |
| --- | --- |
| “异位词”“anagram”“固定长度子串” | LC438 |
| “覆盖”“包含”“最小子串”“最短” | LC76 |

## 5. 模板对比

### LC438 模板

```java
public List<Integer> findAnagrams(String s, String p) {
    int m = s.length(), n = p.length();
    if (m < n) return new ArrayList<>();

    int[] need = new int[26];
    int[] window = new int[26];
    int needClass = 0;
    for (char c : p.toCharArray()) {
        if (need[c - 'a']++ == 0) needClass++;
    }

    List<Integer> res = new ArrayList<>();
    int winClass = 0;
    for (int l = 0, r = 0; r < m; r++) {
        int idx = s.charAt(r) - 'a';
        if (++window[idx] == need[idx]) winClass++;

        if (r - l + 1 > n) {
            int leftIdx = s.charAt(l) - 'a';
            if (window[leftIdx] == need[leftIdx]) winClass--;
            window[leftIdx]--;
            l++;
        }

        if (r - l + 1 == n && winClass == needClass) {
            res.add(l);
        }
    }
    return res;
}
```

### LC76 模板

```java
public String minWindow(String s, String t) {
    char[] cs = s.toCharArray();
    char[] ct = t.toCharArray();
    int[] cnts = new int[256];
    for (char c : ct) cnts[c]--;

    int debt = ct.length;
    int start = 0, len = Integer.MAX_VALUE;

    for (int l = 0, r = 0; r < cs.length; r++) {
        if (cnts[cs[r]]++ < 0) debt--;

        if (debt == 0) {
            while (cnts[cs[l]] > 0) cnts[cs[l++]]--;
            if (r - l + 1 < len) {
                len = r - l + 1;
                start = l;
            }
        }
    }
    return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
}
```

## 6. 最容易混淆的点

1. **LC438 用 `if` 缩左，LC76 用 `while` 缩左**
   - 因为 LC438 窗口长度固定，最多只超 1；LC76 要缩到最短。

2. **LC438 要精确匹配，LC76 允许富余**
   - LC438 多一个字符都不行；LC76 多字符可以，还能帮助缩短窗口。

3. **计数方式可以互换，但模板要对应**
   - LC438 也可以用“债务”思想，LC76 也可以用两个数组，但定长/变长的窗口行为不能混。
