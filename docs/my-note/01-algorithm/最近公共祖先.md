# LC235 二叉搜索树的最近公共祖先

## 1. 题目与 LC236 的关系

LC236 是「普通二叉树」的最近公共祖先（LCA）。
LC235 是「二叉搜索树（BST）」的最近公共祖先。

BST 比普通二叉树多了一个关键性质：

> 左子树所有节点值 < 根节点值 < 右子树所有节点值

这个性质让 LCA 问题变得简单很多。

## 2. LC236 的核心思想回顾

LC236 没有大小关系，只能暴力后序遍历：

- 如果 p、q 在 root 的异侧，root 就是 LCA
- 如果都在左子树，LCA 在左边
- 如果都在右子树，LCA 在右边

代码：

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) {
        return root;
    }
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;
    return left == null ? right : left;
}
```

## 3. LC235 的降维思路

在 BST 中，由于有大小关系，我们可以直接判断 p、q 相对于 root 的位置：

- 情况 1：`p.val < root.val && q.val < root.val`
  - p、q 都在 root 的左子树里
  - LCA 一定在左子树，递归去左边找
- 情况 2：`p.val > root.val && q.val > root.val`
  - p、q 都在 root 的右子树里
  - LCA 一定在右子树，递归去右边找
- 情况 3：其他所有情况
  - p、q 分布在 root 两侧，或者其中一个就是 root
  - 此时 root 就是 LCA

**为什么情况 3 直接返回 root？**

因为 BST 的搜索路径是唯一的：

- 从根往下找 p，会走一条唯一路径
- 从根往下找 q，会走一条唯一路径
- 这两条路径的最后一个公共节点，就是 LCA
- 当 p、q 第一次出现在 root 两侧时，这个分叉点就是 LCA

如果 p 或 q 等于 root，那 root 本身就是祖先，而且一定是最近的。

## 4. 递归写法

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null) {
        return null;
    }
    // 都在左子树
    if (p.val < root.val && q.val < root.val) {
        return lowestCommonAncestor(root.left, p, q);
    }
    // 都在右子树
    if (p.val > root.val && q.val > root.val) {
        return lowestCommonAncestor(root.right, p, q);
    }
    // 分居两侧，或其中一个就是 root
    return root;
}
```

## 5. 迭代写法（更优）

BST 的搜索天然适合迭代：

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    TreeNode cur = root;
    while (cur != null) {
        if (p.val < cur.val && q.val < cur.val) {
            cur = cur.left;
        } else if (p.val > cur.val && q.val > cur.val) {
            cur = cur.right;
        } else {
            return cur;
        }
    }
    return null;
}
```

## 6. 复杂度分析

- 时间复杂度：O(H)，H 是树的高度
  - 平衡 BST：O(logN)
  - 退化 BST（链）：O(N)
- 空间复杂度：
  - 递归版：O(H)
  - 迭代版：O(1)

## 7. 与 LC236 对比总结

| 维度 | LC236 普通二叉树 | LC235 二叉搜索树 |
|------|------------------|------------------|
| 已知信息 | 只有父子关系 | 还有大小顺序关系 |
| 遍历方式 | 后序遍历，左右根 | 利用大小直接判断方向 |
| 时间复杂度 | O(N) | O(H)，最好 O(logN) |
| 空间复杂度 | O(H) | 递归 O(H)，迭代 O(1) |
| 核心思想 | 左右子树是否都找到 p、q | p、q 在 root 哪一侧 |

## 8. 一句话记忆

> BST 的 LCA：p、q 都小往左走，都大往右走，分叉处就是答案。
