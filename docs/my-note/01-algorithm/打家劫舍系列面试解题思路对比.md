# 打家劫舍系列面试解题思路综合对比

> 对应题目：LC198 / LC213 / LC337 / LC2560 / LC3840

## 一、五道题总览

| 题号 | 名称 | 核心结构 | 核心限制 | 算法范式 | 时间复杂度 | 空间复杂度 |
|---|---|---|---|---|---|---|
| LC198 | 打家劫舍 I | 线性数组 | 不能偷相邻房间 | 线性 DP | O(n) | O(n) 可优化至 O(1) |

## 二、逐题面试思考路径

### LC198：打家劫舍 I（最经典的入门版）

#### 题意
一排房子，每个房子有一定金额，不能偷相邻两间，求最大金额。

#### 面试思考路径
1. **第一个问题**：走到第 `i` 间房子时，最优解和前面的什么状态有关？
2. **关键观察**：第 `i` 间只有两种选择——偷或不偷。
   - 偷：第 `i-1` 间不能偷，最优值 = `dp[i-2] + nums[i]`
   - 不偷：最优值 = `dp[i-1]`
3. **状态定义**：`dp[i]` 表示前 `i` 间房子能获得的最大金额。
4. **转移方程**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
5. **边界**：`dp[0] = nums[0]`，`dp[1] = max(nums[0], nums[1])`

#### 代码要点
```java
dp[0] = nums[0];
dp[1] = Math.max(nums[0], nums[1]);
for (int i = 2; i < n; i++) {
    dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
}
```

#### 面试加分项
- 空间优化：因为只依赖前两个状态，可用两个滚动变量 `prev2`、`prev1`，空间降到 O(1)。
- 解释为什么这是最优子结构：第 `i` 间的决策只影响 `i+1`，不会回头影响前面，所以可以贪心/DP。

### LC213：打家劫舍 II（环形数组）

#### 题意
房子围成一圈，首尾相邻，其余同 LC198。

#### 面试思考路径
1. **难点**：首尾两间不能同时偷。
2. **破环成链**：既然首尾不能同时出现，那么只有三种情况：
   - 不偷第一家：问题变成偷 `[1, n-1]` 的线性数组。
   - 不偷最后一家：问题变成偷 `[0, n-2]` 的线性数组。
   - 首尾都不偷：一定包含在上面两种情况里。
3. **结论**：答案 = `max(rob(0, n-2), rob(1, n-1))`。
4. 复用 LC198 的逻辑即可。

#### 代码要点
```java
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    return Math.max(robRange(nums, 0, nums.length - 2),
                    robRange(nums, 1, nums.length - 1));
}

private int robRange(int[] nums, int start, int end) {
    int prev2 = 0, prev1 = 0;
    for (int i = start; i <= end; i++) {
        int cur = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

#### 面试加分项
- 为什么只需要分两段？因为环形唯一新增的限制就是“首尾不能同时选”。
- 如果面试官追问“能不能直接在原数组上 DP”，要解释清楚环形的后效性问题。

### LC337：打家劫舍 III（二叉树版）

#### 题意
房子按二叉树连接，父子节点不能同时偷。

#### 面试思考路径
1. **结构变化**：从线性变成了树形，状态转移要分“左子树”和“右子树”。
2. **每个节点的两种状态**：
   - `f(node)`：偷当前节点时，以该节点为根的子树能获得的最大金额。
   - `g(node)`：不偷当前节点时，以该节点为根的子树能获得的最大金额。
3. **转移方程**：
   - 偷当前节点：左右孩子都不能偷。`f(node) = g(left) + g(right) + node.val`
   - 不偷当前节点：左右孩子可偷可不偷，取各自最大值。`g(node) = max(f(left), g(left)) + max(f(right), g(right))`
4. **后序遍历**：先递归处理子树，再处理当前节点。

#### 代码要点
```java
private int[] dfs(TreeNode node) {
    if (node == null) return new int[2];
    int[] left = dfs(node.left);
    int[] right = dfs(node.right);
    int[] res = new int[2];
    res[0] = Math.max(left[0], left[1]) + Math.max(right[0], right[1]); // 不偷
    res[1] = left[0] + right[0] + node.val;                              // 偷
    return res;
}
```

#### 面试加分项
- 每个节点返回一个长度为 2 的数组，这是树形 DP 的常用技巧。
- 可以提及记忆化搜索或带备忘录的 DFS，避免重复计算（虽然本题每个节点只访问一次，已经 O(n)）。

### LC2560：打家劫舍 IV（二分答案 + 贪心验证）

#### 题意
线性数组，不偷相邻，但要求至少偷 `k` 间，目标是最小化“所偷房间中金额的最大值”。

#### 面试思考路径
1. **关键转化**：题目问的是“最小窃取能力”。如果给定一个能力值 `cap`，能否偷至少 `k` 间，且每间金额都不超过 `cap`？
2. **判定问题具有单调性**：
   - 如果能力 `cap` 可行，那么所有 `cap' > cap` 也可行。
   - 如果能力 `cap` 不可行，那么所有 `cap' < cap` 也不可行。
3. **二分答案**：在 `min(nums)` 到 `max(nums)` 之间二分 `cap`。
4. **贪心验证**：给定 `cap`，从左到右能偷就偷（金额 ≤ cap 且不相邻），统计能偷多少间。
   - 贪心策略：能偷就偷，因为越早偷，留给后面的机会越多。

#### 代码要点
```java
public int minCapability(int[] nums, int k) {
    int left = Arrays.stream(nums).min().getAsInt();
    int right = Arrays.stream(nums).max().getAsInt();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (canRob(nums, k, mid)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
}

private boolean canRob(int[] nums, int k, int cap) {
    int count = 0;
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] <= cap) {
            count++;
            i++; // 跳过下一间，保证不相邻
        }
        if (count >= k) return true;
    }
    return false;
}
```

#### 面试加分项
- 解释为什么 `canRob` 用贪心是对的：对于固定的 `cap`，我们要最大化能偷的房间数，从左到右“能偷就偷”不会比“跳过再偷”更差。
- 时间复杂度 O(n log M)，M 是金额范围。

### LC3840：打家劫舍 V（带颜色限制）

#### 题意
线性数组，相邻房间如果颜色相同则不能同时偷，否则可以相邻偷。求最大金额。

#### 面试思考路径
1. **限制放松**：不再是一刀切“相邻不能偷”，而是“相邻且同色才不能偷”。
2. **重新设计状态**：仍然考虑第 `i` 间偷还是不偷。
   - `dp[i][0]`：不偷第 `i` 间时，前 `i` 间的最大金额。
   - `dp[i][1]`：偷第 `i` 间时，前 `i` 间的最大金额。
3. **转移方程**：
   - `dp[i][0] = max(dp[i-1][0], dp[i-1][1])`
   - `dp[i][1]` 需要判断 `i-1` 和 `i` 是否同色：
     - 同色：第 `i-1` 间不能偷，`dp[i][1] = dp[i-1][0] + nums[i]`
     - 不同色：第 `i-1` 间可偷可不偷，`dp[i][1] = max(dp[i-1][0], dp[i-1][1]) + nums[i]`
4. 也可以压缩成一维滚动变量。

#### 代码要点
```java
public long rob(int[] nums, int[] colors) {
    int n = nums.length;
    long notRob = 0; // 不偷上一间
    long robPrev = nums[0]; // 偷上一间
    
    for (int i = 1; i < n; i++) {
        long notRobCur = Math.max(notRob, robPrev);
        long robCur;
        if (colors[i] == colors[i - 1]) {
            robCur = notRob + nums[i];
        } else {
            robCur = Math.max(notRob, robPrev) + nums[i];
        }
        notRob = notRobCur;
        robPrev = robCur;
    }
    return Math.max(notRob, robPrev);
}
```

#### 面试加分项
- 把状态拆成“偷/不偷”两个维度，是处理相邻限制类 DP 的通用技巧。
- 颜色限制只是把 LC198 的“恒不可偷”变成了“条件不可偷”。

## 四、面试应答策略总结

### 1. 看到“不能相邻”→ 先想 DP
无论数组、环形数组、树，核心都是：**每个元素选或不选，且不选相邻元素**。状态设计围绕“选/不选”展开。

### 2. 结构变形
- **线性**：一维 DP。
- **环形**：拆成两条链分别做线性 DP，取 max。
- **树形**：树形 DP，每个节点返回多状态数组，后序遍历。

### 3. 目标函数变形
- **最大总金额**：直接 DP。
- **最小化最大值 / 最大化最小值 / 至少选 k 个**：优先考虑**二分答案 + 贪心验证**。

### 4. 限制条件变形
- 不是所有相邻都不能选时，状态维度扩展到“偷/不偷”，根据相邻条件决定是否允许转移。

### 5. 空间优化
线性 DP 几乎都可以压缩成 O(1) 滚动变量，面试中主动提及是加分项。
