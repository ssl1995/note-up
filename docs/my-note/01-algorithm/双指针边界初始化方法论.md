# 双指针边界初始化方法论：从区间定义推导，拒绝死记硬背
## 一、问题背景
写荷兰国旗（LC75 颜色分类）、快速排序分区这类双指针算法时，最容易出错的不是思路，而是指针初始化：
- `left` 到底初始化成 `0` 还是 `-1`？
- `right` 到底初始化成 `n-1` 还是 `n`？
- 循环条件到底写 `i < right` 还是 `i <= right`？
- 交换时用 `left++` 还是 `++left`？
**核心认知**：这些不是四套需要背的组合，而是由"区间定义"一个源头推导出来的必然结果。面试时只要讲清楚区间不变量，初值和边界条件可以现场推导，绝不会错。
## 二、第一性原理：不变量决定一切
双指针算法的本质是维护**区间不变量（Invariant）**。以荷兰国旗为例，任意时刻数组被划分为：
```
[  0区  |  未知区  |  2区  ]
```
只要用一句话定义清楚每个指针是什么边界，剩下的写法全部被唯一确定。**先定义，后写码，顺序不能反。**
## 三、四步推导法（面试现场版）
### 第 1 步：画分区图，口头说出不变量
先对面试官说出类似这样的话：
> "我维护这样的不变量：`[0, left)` 全是 0，`(right, n-1]` 全是 2，中间 `[i, right]` 是还没看的元素。"
### 第 2 步：初始化 = 让"已处理区为空"
循环还没开始时，整个数组都是未知的，所以 0 区和 2 区必须是空集。这条原则唯一确定初值：
| 区间定义 | 为空时的初值 |
|------|------|
| `[0, left)` 是 0 区（左闭右开） | `left = 0` |
| `[0, left]` 是 0 区（闭区间） | `left = -1` |
| `(right, n-1]` 是 2 区（左开右闭） | `right = n - 1` |
| `[right, n-1]` 是 2 区（闭区间） | `right = n` |
**记忆点**：开区间那一侧，指针指向"下一个待写入位置"；闭区间那一侧，指针指向"边界外一格"。
### 第 3 步：循环条件 = "未知区非空"
| 未知区定义 | 循环条件 |
|------|------|
| 未知区是闭区间 `[i, right]` | `while (i <= right)` |
| 未知区是 `[i, right)` | `while (i < right)` |
### 第 4 步：交换后指针动不动，看"换来的元素检查过没有"
- **见 0 换左边**：`left` 位置在 `i` 左边或与 `i` 重合，换过来的元素**已经检查过**（是 1 或自己），所以 `i++` 安全。
- **见 2 换右边**：`right` 位置在 `i` 右边，换过来的元素**还没检查**，所以 `i` 不能动，下一轮继续看它。
## 四、两种等价写法对照（都对，选一种用到底）
### 写法 A：左闭右开（推荐，少一层心智负担）
```java
// 不变量：[0,left) 是0区，(right,n-1] 是2区，[i,right] 未知
int left = 0, right = nums.length - 1, i = 0;
while (i <= right) {          // 未知区 [i,right] 非空
    if (nums[i] == 0) {
        swap(nums, left++, i++);   // 换来的已检查，i 右移
    } else if (nums[i] == 1) {
        i++;
    } else {
        swap(nums, right--, i);    // 换来的没检查，i 不动
    }
}
```
### 写法 B：闭区间
```java
// 不变量：[0,left] 是0区，[right,n-1] 是2区，(left,right) 未知
int left = -1, right = nums.length, i = 0;
while (i < right) {           // 未知区 [i,right) 非空
    if (nums[i] == 0) {
        swap(nums, i++, ++left);
    } else if (nums[i] == 1) {
        i++;
    } else {
        swap(nums, i, --right);    // i 不动
    }
}
```
**两种写法都正确**（已用 10 万组随机用例对拍验证）。真正会出 bug 的是**混着写**。
## 五、常见的错误混搭（反面教材）
| 错误组合 | 后果 |
|------|------|
| `right = n` 却用 `while (i <= right)` | 数组越界 |
| `right = n - 1` 却用 `while (i < right)` | 漏掉最后一个元素未处理 |
| `left = 0` 却用 `swap(nums, i, ++left)` | 跳过 nums[0]，0 区错位 |
| `left = -1` 却用 `swap(nums, i, left++)` | 交换到下标 -1，越界 |
**规律**：错的都是"初始化和后面用法不配套"。只要第 1 步的不变量想清楚，后面的写法全是推导结果，不存在背错的可能。
## 六、方法迁移：这套推导法通用
同样的"先定义区间、再推导边界"适用于所有双指针/二分场景：
1. **快速排序 partition**：定义 `[0, p)` 小于 pivot、`[p, i)` 大于等于 pivot，初始化 `p = 0`（已处理区为空），交换逻辑随之确定。
2. **二分查找**：定义搜索区间是 `[l, r]` 还是 `[l, r)`，直接决定初值（`r = n-1` 还是 `n`）、循环条件（`l <= r` 还是 `l < r`）和收缩方式（`r = mid - 1` 还是 `r = mid`）。
3. **滑动窗口**：定义窗口是 `[l, r]` 闭区间，右扩左缩的写法随之确定。
## 七、面试口诀
> **先定区间语义 → 初始让已处理区为空 → 循环条件 = 未知区非空 → 换右不动 i，换左动 i**
在白板上把分区图画出来、把不变量说给面试官听，初值和边界条件就是顺水推舟的推导结果——不用背，也不会错。
