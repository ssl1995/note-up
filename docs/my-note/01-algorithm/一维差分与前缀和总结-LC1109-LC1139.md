# 一维差分与前缀和总结（LC1109 / LC1139）
> 说明：LC1109 航班预定统计 = **一维差分**（多次区间修改 + 最后统一查询）；LC1139 最大的以1为边界的正方形 = **前缀和**（二维，但用的是 in-place 0-based 风格，与 LC2132 的 1-based 风格形成对照）。
## 一、一维差分（LC1109 航班预定统计）
### 1. 题目与套路识别
- 题意：n 个航班（编号 1~n），每条预订记录 `[first, last, seats]` 给 `[first, last]` 区间每个航班 `+seats`，求最终每个航班的座位总数。
- 特征：**多次区间修改 + 只在最后查一次结果** → 一维差分标准场景。
- 对比：若每次修改后都要查询 → 差分不适用（需线段树/树状数组）；若只是多次查询不改 → 用前缀和。
### 2. 核心公式
对区间 `[l, r]` 统一 `+v`，只动 **2 个点**：
```
diff[l] += v;      // 区间起点：+
diff[r + 1] -= v;  // 区间终点的下一个位置：-
```
最后**从左到右求一遍前缀和即还原原数组**：
```
cnt[i] += cnt[i - 1]
```
口诀：**起点加、终点后一位减**（二维差分"四角操作"的一维退化版）。
### 3. 初始化
| 项 | 值 | 原因 |
| --- | --- | --- |
| 长度 | `new int[n + 2]` | 航班编号 1~n 是 1-based，多留 index 0；且 `r+1` 最大到 `n+1`，所以 +2 |
| 初始值 | 全 0（Java 默认） | 表示一开始每个航班预订数为 0 |
### 4. 完整代码与示例推演
```java
public int[] corpFlightBookings(int[][] bookings, int n) {
  int[] cnt = new int[n + 2];            // 1、差分数组
  for (int[] book : bookings) {
    cnt[book[0]] += book[2];             // 起点 +
    cnt[book[1] + 1] -= book[2];         // 终点后一位 -
  }
  for (int i = 1; i < n + 2; i++) {      // 2、前缀和还原
    cnt[i] += cnt[i - 1];
  }
  int[] res = new int[n];                // 3、截取 1~n 号航班
  System.arraycopy(cnt, 1, res, 0, n);
  return res;
}
```
输入 `bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5`，逐步推演：
| 步骤 | cnt 数组（下标 0~6） |
| --- | --- |
| 初始 | `[0, 0, 0, 0, 0, 0, 0]` |
| [1,2,10]：cnt[1]+10，cnt[3]-10 | `[0, 10, 0, -10, 0, 0, 0]` |
| [2,3,20]：cnt[2]+20，cnt[4]-20 | `[0, 10, 20, -10, -20, 0, 0]` |
| [2,5,25]：cnt[2]+25，cnt[6]-25 | `[0, 10, 45, -10, -20, 0, -25]` |
| 前缀和还原 | `[0, 10, 55, 45, 25, 25, 0]` |
| 截取 [1..5] | `[10, 55, 45, 25, 25]` ✓ |
复杂度：修改 `O(bookings)`，还原 `O(n)`，远优于暴力逐区间累加的 `O(bookings × n)`。
## 二、前缀和（LC1139 最大的以1为边界的正方形）
### 1. 题目与套路识别
- 题意：01 矩阵中找边界全由 1 组成的最大正方形，返回其元素数量（面积）。
- 特征：**需要反复查询各种矩形区域的和**（判断边界是否全 1）→ 前缀和标准场景。
- 判定技巧：枚举正方形左上角 `(a,b)` 和右下角 `(c,d)`，边长 k：
```
外正方形区域和 outside = sum(a, b, c, d)
内正方形区域和 inside  = sum(a+1, b+1, c-1, d-1)
期望周长 round = (k - 1) * 4
outside - inside == round  ⟹  边界一圈全为 1
```
### 2. 本题亮点：in-place 0-based 风格（与 LC2132 的 1-based 风格对照）
本题**不开新数组、不留哨兵行**，直接在原 grid 上累加，越界用 `get()` 守卫返回 0：
```java
private void build(int[][] grid, int m, int n) {
  for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
      grid[i][j] += get(grid, i, j - 1) + get(grid, i - 1, j) - get(grid, i - 1, j - 1);
}
private int sum(int[][] grid, int a, int b, int c, int d) {
  if (a > c) return 0; // 内缩一层后不能构成正方形（边长为1时 a+1 > c-1）
  return get(grid, c, d) - get(grid, c, b - 1) - get(grid, a - 1, d) + get(grid, a - 1, b - 1);
}
private int get(int[][] grid, int i, int j) {
  return i < 0 || j < 0 || i > grid.length - 1 || j > grid[0].length - 1 ? 0 : grid[i][j];
}
```
**两种前缀和实现风格对照表**：
| 对比项 | LC2132 风格（1-based） | LC1139 风格（0-based in-place） |
| --- | --- | --- |
| 数组 | 新开 `sum[m+1][n+1]` | 直接改原数组，省空间 |
| 下标 | 整体偏移 1 格 | 与原数组一致 |
| 边界处理 | 第 0 行/列哨兵，天然为 0 | `get()` 方法越界返回 0 |
| build 起点 | 从 `i=1, j=1` 开始 | 从 `i=0, j=0` 开始 |
| 副作用 | 不改原数组 | **会污染原始数据**（原 grid 被破坏） |
| 查询公式 | `sum[c][d] - sum[a-1][d] - sum[c][b-1] + sum[a-1][b-1]` | 同左，坐标含义换成 0-based |
两种风格公式本质相同（容斥原理），区别只在**边界怎么挡**：哨兵行 vs get 守卫。面试中 1-based 更不易错；in-place 更省内存但会改坏入参。
### 3. 剪枝优化
```java
int res = 1; // 已确认数组不全为0，至少有 1×1 的正方形
for (int a = 0; a < m; a++)
  for (int b = 0; b < n; b++)
    // c、d 从 a+res、b+res 开始：只找比当前答案更大的正方形
    for (int c = a + res, d = b + res, k = res + 1; c < m && d < n; c++, d++, k++) {
      ...
      if (outside - inside == round) res = k;
    }
return res * res; // 返回面积
```
- 前置判断：全矩阵和为 0 → 直接返回 0（连 1 都没有）。
- 内层从 `res + 1` 边长开始枚举，已找到的答案不会再被更小的覆盖。
### 4. 示例推演
输入 `grid = [[1,1,1],[1,0,1],[1,1,1]]`：
- build 后前缀和数组（grid 中 1 共 8 个，中心是 0）：
```
1  2  3
2  4  6
3  6  8
```
- 枚举 `(a,b)=(0,0)`、`(c,d)=(2,2)`，边长 k=3：
  - `outside = sum(0,0,2,2) = 8`（整个 3×3 区域的和，即前缀和数组右下角）
  - `inside  = sum(1,1,1,1) = 0`（中心格子是 0）
  - `round = (3-1)×4 = 8`（3×3 正方形边界的格子数）
  - `outside - inside = 8 - 0 = 8 == round` ✓ 边界全为 1
- 所以 res = 3，返回面积 3×3 = 9。
## 三、一维 vs 二维对照速查
| 对比项 | 一维差分（LC1109） | 二维差分（LC2132/LCP74） | 前缀和（LC1139/LC304） |
| --- | --- | --- | --- |
| 修改/查询操作点 | 2 个点：`l`、`r+1` | 4 个角：`(a,b)`、`(c+1,b)`、`(a,d+1)`、`(c+1,d+1)` | 查询 4 个角：`cd`、`a-1行`、`b-1列`、`a-1,b-1` |
| 符号口诀 | 起点加、终点后一位减 | 左上加、右下加，另外两个减 | 右下角 − 上 − 左 + 左上角 |
| 还原/构建 | 从左到右累加一次 | 二维前缀和累加（容斥） | 二维前缀和累加（容斥） |
| 数组长度 | `n + 2` | `(m+2) × (n+2)` | `(m+1) × (n+1)` 或 in-place |
| 适用场景 | 多次区间改 + 最后查 | 多次矩形改 + 最后查 | 静态数组多次查区域和 |
## 四、易错点清单
1. **LC1109 数组开 `n+2`**：航班 1-based 占位 +1，`r+1` 可能等于 `n+1` 再 +1，漏掉会越界。
2. **还原后才能读结果**：差分数组不做前缀和累加，直接读是增量不是真实值。
3. **LC1139 会改坏入参**：in-place build 之后 grid 不再是原始数据，若后续还要用原数组需先拷贝。
4. **内正方形越界**：边长为 1 时 `sum(a+1, b+1, c-1, d-1)` 出现 `a > c`，必须返回 0 防护（本题 sum 里的 `if (a > c) return 0`）。
5. **周长公式**：边长 k 的正方形边界格子数 = `(k-1) × 4`，不是 `k × 4`（四个角被两条边共用）。
6. **返回的是面积**：`res * res`，不是边长 res。
7. **get() 守卫边界要写全**：`i<0 || j<0 || i>m-1 || j>n-1`，四个方向缺一不可。
