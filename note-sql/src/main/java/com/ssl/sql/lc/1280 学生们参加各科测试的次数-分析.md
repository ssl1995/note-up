# 1280. 学生们参加各科测试的次数
## 1. 题目描述
**表结构：**
- `Students`：`student_id`（主键）、`student_name`
- `Subjects`：`subject_name`（主键）
- `Examinations`：`(student_id, subject_name)` 联合主键
**目标：** 查询每个学生参加每一门科目测试的次数，结果按 `student_id` 和 `subject_name` 排序。
**关键要求：** 结果必须包含所有学生和所有科目的组合，即使测试次数为 0。
## 2. SQL 考点分析
| 考点 | 说明 |
|------|------|
| **CROSS JOIN（笛卡尔积）** | 生成所有学生 × 所有科目的完整组合，确保结果包含 0 次记录 |
| **LEFT JOIN** | 左连接保留左表全部数据，右表无匹配时补 NULL |
| **GROUP BY 聚合** | 按学生+科目分组，统计考试次数 |
| **COUNT() 函数** | `COUNT(e.subject_name)` 只统计非 NULL 值，NULL 时返回 0 |
| **多表连接** | 三表关联：Students、Subjects、Examinations |
| **排序** | `ORDER BY student_id, subject_name` 保证输出顺序 |
## 3. 常见解法
### 解法一：CROSS JOIN + LEFT JOIN（推荐 / 最优）
先用 `CROSS JOIN` 生成所有学生与科目的组合，再 `LEFT JOIN` 考试表统计次数。
```sql
SELECT 
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.subject_name) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN Examinations e 
    ON s.student_id = e.student_id 
    AND sub.subject_name = e.subject_name
GROUP BY s.student_id, s.student_name, sub.subject_name
ORDER BY s.student_id, sub.subject_name;
```
**优点：**
- 逻辑清晰，一步到位
- 确保所有组合都出现，包括 0 次
- 只需要一次 `GROUP BY`
**缺点：**
- `CROSS JOIN` 会产生笛卡尔积，数据量大时内存消耗高
### 解法二：子查询先聚合，再连接
先在 `Examinations` 表内按学生+科目聚合，再与 Students、Subjects 连接。
```sql
SELECT 
    s.student_id,
    s.student_name,
    sub.subject_name,
    COALESCE(e.attended_exams, 0) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN (
    SELECT student_id, subject_name, COUNT(*) AS attended_exams
    FROM Examinations
    GROUP BY student_id, subject_name
) e ON s.student_id = e.student_id AND sub.subject_name = e.subject_name
ORDER BY s.student_id, sub.subject_name;
```
**优点：**
- 先聚合减少连接数据量，性能更好
- 使用 `COALESCE` 处理 NULL 为 0
**缺点：**
- 需要子查询，代码稍复杂
### 解法三：使用 `IFNULL` / `COALESCE` 处理 NULL
与解法二类似，但用 `IFNULL`（MySQL）或 `COALESCE`（标准 SQL）处理 NULL。
```sql
SELECT 
    s.student_id,
    s.student_name,
    sub.subject_name,
    IFNULL(e.cnt, 0) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN (
    SELECT student_id, subject_name, COUNT(*) AS cnt
    FROM Examinations
    GROUP BY student_id, subject_name
) e ON s.student_id = e.student_id AND sub.subject_name = e.subject_name
ORDER BY s.student_id, sub.subject_name;
```
## 4. 最优 SQL
**推荐解法一（CROSS JOIN + LEFT JOIN）**，原因如下：
1. **语义最清晰**：直接表达"所有学生 × 所有科目"的业务含义
2. **代码简洁**：不需要子查询，一次 `GROUP BY` 完成
3. **性能可接受**：LeetCode 数据量小，`CROSS JOIN` 开销可忽略
4. **NULL 处理自然**：`COUNT(e.subject_name)` 自动将 NULL 计为 0
```sql
SELECT 
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.subject_name) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN Examinations e 
    ON s.student_id = e.student_id 
    AND sub.subject_name = e.subject_name
GROUP BY s.student_id, s.student_name, sub.subject_name
ORDER BY s.student_id, sub.subject_name;
```
## 5. 易错点提醒
| 易错点 | 说明 |
|--------|------|
| **忘记 CROSS JOIN** | 直接 `LEFT JOIN` 会导致缺少 0 次记录的组合 |
| **COUNT(*) vs COUNT(列名)** | `COUNT(*)` 会统计 NULL 行，必须用 `COUNT(e.subject_name)` |
| **GROUP BY 字段不全** | 必须包含 `student_id`、`student_name`、`subject_name` |
| **排序字段错误** | 必须按 `student_id, subject_name` 排序，不是 `student_name` |
## 6. 小结
| 解法 | 核心思想 | 推荐指数 | 适用场景 |
|------|---------|---------|---------|
| **CROSS JOIN + LEFT JOIN** | 笛卡尔积生成全组合，左连接统计 | ⭐⭐⭐⭐⭐ | **推荐，语义清晰** |
| 子查询先聚合 | 先聚合再连接，减少连接量 | ⭐⭐⭐⭐ | 大数据量优化 |
| `IFNULL`/`COALESCE` | 处理 NULL 为 0 | ⭐⭐⭐ | 与解法二配合使用 |
**结论：** 本题最优解是 **CROSS JOIN + LEFT JOIN**，它能完整覆盖所有学生-科目组合，且代码简洁易懂。
